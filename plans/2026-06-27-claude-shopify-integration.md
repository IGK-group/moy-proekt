# План: интеграция Claude в Shopify

**Дата:** 2026-06-27
**Автор:** Гена + Claude
**Статус:** в работе

## Цель

Подключить Claude (Anthropic API) к Shopify-магазину MebelShop и автоматизировать первую рутинную задачу.

## Контекст

MebelShop строится на Shopify. Магазин ещё не создан. Прежде чем писать код — нужно понять архитектуру, выбрать юзкейс, настроить среду. Только потом — реализация.

## Гипотезы

- Claude встраивается через внешнее приложение (не нативно в Shopify Liquid)
- Самый быстрый старт — Shopify Admin API + скрипт на Node.js без полноценного App
- Первый юзкейс: генерация описаний товаров — не требует работы в реальном времени и не зависит от трафика

## Риски

- Shopify ограничивает кастомный код на базовых тарифах — уточнить до фазы 3
- Claude API платный — заложить в расходы с первого дня
- Без опыта в разработке фаза 4 потребует пошаговой помощи Claude

## Фазы

### Фаза 1. Создать Shopify-магазин
**Результат:** работающий тестовый магазин с Admin API доступом

- [ ] Зарегистрироваться на Shopify (shopify.com → Start free trial)
- [ ] Выбрать тариф (Basic достаточно для старта)
- [ ] Создать private app: Admin → Settings → Apps → Develop apps
- [ ] Выдать права: `read_orders`, `write_products`, `read_analytics`
- [ ] Скопировать Admin API access token → положить в `.env` как `SHOPIFY_ADMIN_TOKEN`
- [ ] Вписать Store URL в `business/life-metrics.md`
