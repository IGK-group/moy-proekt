## Контент-стратегия

**Органика без платной рекламы** через Instagram + TikTok.

Формат каждого видео:
```
[0-10 сек] AI-хук (Higgsfield Seedance 2.0 Omni Reference, 9:16)
         +
[10-60 сек] Демо-видео товара (с CJ/AliExpress страницы поставщика)
         =
Вирусный ролик → ссылка в bio → Linktree → Shopify product page → продажа
```

Текстовый контент: Claude Code + промт Ривера (21 единица из одного сценария).
Публикация: GeeLark RPA по расписанию.
