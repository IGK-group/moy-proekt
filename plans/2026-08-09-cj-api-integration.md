# План: интеграция CJdropshipping API для наполнения магазина

**Дата:** 2026-08-09
**Статус:** [x] Завершено на сегодня - 4 товара в магазине, все реально привязаны к CJ через нативный листинг (не через прямое создание в Shopify API - см. Фазу 6, это оказалось критично)

---

## Идея

Заменить ручной подбор товаров в приложении CJdropshipping на программный: искать товары в каталоге CJ через их открытый API и напрямую создавать карточки в Shopify (`ghnjxs-hh.myshopify.com`) через уже рабочий Admin API (`shopify-tools/*.py`).

Контекст: CJdropshipping установлен 2026-08-09 как полная замена ручной закупки на 1688/Taobao для активного потока (умные гаджеты, без живой съёмки) - см. `business/products/overview.md` и `../CLAUDE.md`. Приоритет по товарам уже определён через DataForSEO-разведку (`business/products/niche-candidates.md`):
- **Window cleaning robot** - приоритет №1, прибыль/заказ $21
- **Robot vacuum and mop** - приоритет №2, прибыль/заказ $42

## Фазы

- [x] **Фаза 1 - Доступ к CJ API** (2026-08-09)
  - API Key получен и записан в `shopify-tools/.env` как `CJ_API_KEY`
  - `shopify-tools/cj_auth.py` - обмен ключа на accessToken/refreshToken, запись в `.env` (`CJ_ACCESS_TOKEN`, `CJ_REFRESH_TOKEN`, `CJ_ACCESS_TOKEN_EXPIRY`)
  - Проверено: подключение работает, access token действителен до 2027-02-05

- [x] **Фаза 2 - Поиск товаров в каталоге CJ** (2026-08-09)
  - `shopify-tools/cj_search.py` - поиск по ключевым словам через `product/listV2`, rate-limit 1 QPS с ретраем на 429
  - **Важный вывод:** фильтры `verifiedWarehouse=1 + countryCode=US` почти полностью прячут обе ниши - реальные товары лежат на китайском складе, не в "verified US". Без этих фильтров (`country_code=None, verified_only=False`) находятся настоящие кандидаты.
  - Window cleaning robot нашёлся только по запросу `"robot window cleaner"` (без фильтров) - по прямым фразам вроде "window cleaning robot" выдача не по теме (вода не тот товар, а мойки окон/сетки/сигнализации)
  - Один кандидат (Geek Smart Robot Vacuum Cleaner G6, $136.84) отсеян - в названии от CJ пометка **"Banned From Selling On Amazon"**, реселл через Doba, пустое описание, нереалистичный suggestSellPrice x7.4 - не добавлен

- [x] **Фаза 3 - Импорт в Shopify** (2026-08-09) - `shopify-tools/cj_create_products.py`
  - **DYP Automatic Window Cleaning Robot** (CJ pid `1382262788063367168`, $85.65 COGS, 3 варианта вилки EU/UK/US) -> Shopify product_id `9105008951473`, цена $249.99
  - **Yq16pro Smart Robot Vacuum & Mop** (CJ pid `2014591964245168129`, $88.00 COGS, auto-recharge + app control, включает переходники EU/US/UK/AU) -> Shopify product_id `9105008984241`, цена $279.99
  - Остатки выставлены (22 шт/вариант) через `inventory_levels/set.json`
  - **Пересчёт экономики по факту:** реальный COGS у CJ оказался выше, чем черновая оценка в `niche-candidates.md` (22-25% от цены). Итоговая цена по window cleaning robot поднята с модельных $130 до $249.99 (иначе убыток), по robot vacuum - с $280 до $279.99 фактически совпало. Ориентировочная чистая прибыль/заказ при ROAS 3.0: ~$18-21, не $21-42 как в черновой прикидке - модель в `unit_economics.py` использовала % от цены вместо реального CJ-прайса, точность стоит поднять при следующем отборе.

- [x] **Фаза 4 - Проверка логистики** (2026-08-09)
  - Реальные сроки/цены доставки CJ->US проверены через `/logistic/freightCalculate`: 4-9 дней в пути (не 3-9 дней "из воздуха", как в черновой модели) + 1-2 дня обработка CJ = ~5-11 рабочих дней итого
  - Реальный фрахт оказался дороже черновой оценки: $30-46 за посылку (не $9-20, как в `unit_economics.py`) - формула "COGS + freight + 3PL + последняя миля" вообще не подходит для прямого CJ-дропшиппинга: это одна ставка от Китая до двери, без промежуточных звеньев (3PL/последняя миля - не нужны, убраны из расчёта)
  - Магазин ещё под паролем (Opening soon) - живого трафика нет, снять пароль отдельным решением

Скрипт переписан на `ORGANIC_CAC=10` (плановая оценка из `content-factory/architecture.md`, выведена под мебельный поток, НЕ подтверждена для гаджетов, контент-завод ещё не подключён - см. предупреждение в коде скрипта)

Не пересматривался отдельно, зафиксировано на будущее.
  - Добавлены 2 бюджетные альтернативы (те же ниши, дешевле):

- [x] **Фаза 6 - КРИТИЧНО: ORDINARY_PRODUCT vs SUPPLIER_PRODUCT** (2026-08-09)
  - Обнаружено: у CJ есть два типа товаров в их API - `productType: "ORDINARY_PRODUCT"` (их собственный каталог) и `productType: "SUPPLIER_PRODUCT"` (реселл от стороннего поставщика на площадке CJ). **Второй тип нельзя привязать к магазину через штатный флоу приложения ("Add Product" в CJ его физически не находит по SKU, хотя товар существует и виден через API)** - значит для него не будет автообработки заказов вообще.
  - И Yq16pro ($88 COGS, auto-recharge+app), и первый вариант бюджетного пылесоса (Black Robot Vacuum Mop, $43.40 COGS) оказались `SUPPLIER_PRODUCT` - несмотря на то, что оба легитимные, качественные листинги. Пришлось искать замену.
  - Проверка на будущее перед выбором любого нового товара: `product/query` -> поле `productType` -> `ORDINARY_PRODUCT` = можно; `SUPPLIER_PRODUCT` = скорее всего нельзя (не проверено, есть ли обходной путь через саппорт CJ). В `listV2` тот же признак числом: `"productType": "0"` = ORDINARY, `"4"` = SUPPLIER.
  - Пытался связать товар и Shopify-карточку напрямую через API (`product/conn/connection`) в обход интерфейса - нашёл рабочий эндпоинт, подтвердил 2 обязательных поля (`platformProductId`, `defaultArea`) методом проб, но дальше API возвращал общую ошибку формата без документации. **Сознательно остановился** - это write-операция, которая напрямую маршрутизирует исполнение реальных заказов, гадать вслепую на ней рискованно. Нашёл смежный документированный эндпоинт `POST /product/addToMyProduct` (нужен только `productId`) - рабочий, но решает только первый шаг ("добавить в список"), не шаг листинга в магазин с ценами/доставкой - тот, судя по всему, вообще не задокументирован как отдельный API.
  - **Итоговая замена (оба ORDINARY_PRODUCT, реально привязаны через нативный "List" флоу в приложении CJ):**
    - **Intelligent Window Cleaning Robot** (CJ SKU `CJJT1080244`, $85.65 COGS, 3 варианта EU/UK/US, доставка CJPacket Sensitive $44.59) -> $249.99, прибыль ~$60/заказ (ниже черновой оценки из-за реальной цены доставки)

    - **Beautiful Jieshi Sweeping Robot** (CJ SKU `CJYD2065091`, White $34.94 / Black $72.39 COGS - разница в цене между цветами ничем не объясняется в данных CJ, полная проверка описания/веса/спецификации показала идентичные характеристики) -> White $149.99, Black $189.99, доставка $46.05 - замена Black Robot Vacuum Mop

## Открытые вопросы

- Rate limit CJ API: 1 запрос/сек - учитывать при массовом импорте
- Нужно ли переводить описания на английский (магазин ориентирован на US/EU рынок) - да, проверено: карточки CJ уже на английском
- Поиск в CJ по прямым фразам ниши ненадёжен (много нерелевантной выдачи, реальные товары иногда только без гео/verified фильтров) - при масштабировании на другие ниши закладывать время на перебор формулировок, не полагаться на первый запрос
- **Товары теперь создаются через нативный "List" флоу в приложении CJ (руками в браузере), не через `cj_create_products.py`** - скрипт устарел для будущих добавлений, он создавал товары в обход CJ, что оказалось нерабочим для SUPPLIER_PRODUCT и не даёт автообработку заказов вообще. Оставлен в репозитории справочно
- [x] **Решено (2026-08-09):** пошлина США **уже включена** в стоимость доставки CJ - подтверждено всплывающей подсказкой в самом интерфейсе CJ: "Налог в размере 15% от заявленной стоимости уже включён в стоимость доставки". Поля `taxesFee: 0`/`clearanceOperationFee: 0` в API вводили в заблуждение - похоже, это просто означает "не выставляется отдельной строкой", а не "не входит вообще". Блог CJ (https://blog.cjdropshipping.com/detail/How-CJdropshipping-Helps-You-Adapt-to-New-U-S--Tariffs) подтверждает: с 2 мая 2025 тарифные сборы включены прямо в ставку фрахта (выросла на ~25% из-за этого).
  - **Итог: в расчётах прибыли отдельная строка "пошлина 30%" убрана** - она задваивала расход (15% уже сидело внутри цены доставки CJ). Реальная чистая прибыль/заказ (минус $10 органического CAC) оказалась выше прежних оценок:
    - Intelligent Window Cleaning Robot (DYP): ~$100 (было ~$60)
    - Window-cleaning Robot budget: ~$42 (было ~$20)
    - Ultra-Thin Automatic Refilling: ~$35-70 в зависимости от уровня A/B/C (при единой цене $199.99)
    - Beautiful Jieshi (White $149.99 / Black $189.99): ~$53 у обоих цветов
  - Остаётся не до конца ясным конкретно у DHL/премиальных линий - тот же процент 15%, или другая логика (не проверялось отдельно)
