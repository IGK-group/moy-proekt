# plans/ — технические планы реализации

Место для планов реализации функций. Один план = одна функция.

## Правила

1. **Один план = одна функция.** Если план уже существует — работай с ним, не создавай новый.
2. **Имя файла:** `YYYY-MM-DD-название-функции.md`
3. **Структура плана:** фазы со статусом `[ ]` (не сделано) или `[x]` (готово).
4. **В конце каждого плана** — итоговый блок: реализован целиком / частично / не реализован, что осталось.
5. **Любой агент обязан актуализировать план** после каждой сессии: отмечать сделанное, дописывать изменения.

## Цикл работы с новой функцией

- **Чат 1** — формирует план: описывает задачу, цель, ограничения.
- **Чат 2** — разбивает план на конкретные фазы с шагами.
- **Чат 3** — проверяет каждую фазу на адекватность: реально ли, нет ли противоречий.
- **Чат 4+** — реализация по фазам.

## Зачем

Новый чат Клода не помнит прошлого. **План — помнит.** Клод читает план, видит где остановились — и продолжает оттуда без потери контекста.
