## Часть 1. Топ-5 уроков (исследования)

1. **Люди не читают — сканируют.** NN/G: 79% всегда только сканируют, дословно читают 16%. Прочитывается 20-28% текста. F-паттерн (2 горизонтальных «взгляда» сверху + вертикальный слева). => смысл по заголовкам и первым словам; абзац 3 строки без выделений в зоне сканирования = потерян.
2. **Whitespace разделяет контент, а не заменяет его.** Экран пустоты между секциями читается как «страница кончилась» → разворот. Текст и картинка выровнены по вертикали.
3. **Главная за 1 экран показывает что и как купить.** Baymard (25 раундов тестов, 344 топ-магазина): явно показать 3 пути — категории, поиск, curated; на главной ≥40% типов товаров; трудно найти цену/инфо → сомнение → отказ.
4. **Заголовок и «убрать лишнее» — самый большой прирост.** Оптимизация заголовка +27-104%; убрать отвлекающее +~10%; описания «выгода первой», детали таблицей.
5. **Корзину бросают из-за сюрпризов и трения.** Baymard: бросают 70-78%. Неожиданная доставка/налоги 40-48%, принудительная регистрация 26%, долгий чекаут 17%, зависание 9%. Мобильный — худший (~80%). Доверие = отзывы (у нас нет вообще).

Sources: nngroup.com/articles/f-shaped-pattern-reading-web-content-discovered/ · baymard.com/research/homepage-and-category-usability · baymard.com/lists/cart-abandonment-rate · leadfeeder.com/blog/conversion-optimization/landing-pages-convert/ · makecommerce.net/product-landing-page-best-practices-2026-... · brandedagency.com/blog/high-converting-landing-pages · uxpin.com/studio/blog/website-design-for-scannability/

## Часть 2. Аудит — где теряем посетителя

### Зона, которую выделил Гена (после категорий → «How it actually performs»)
- ~1 экран пустоты между плитками категорий и первой цифрой (отступ секции категорий 72px + Innovations сверху 84px + огромный центрированный H2 в 3 строки с большими полями). При сканировании обрывается нить → уход. [урок 2]
- Заголовок «You run it from your phone. It does the rest.» занимает пол-экрана сам по себе. [урок 1,2]
- Плитки: под текстом пусто, «Shop … →» дублирует заголовок плитки. [урок 1]

### Весь сайт (по критичности)

**Критично:**
1. На главной ни одного реального товара с ценой и кнопкой купить. Каталог за 2 клика (плитка → коллекция). [урок 3]
2. Hero продаёт то, чего нет в магазине (Vac Station / Stick V400 / Mite Pro). Клик → тупик / несоответствие ожиданий. (Гена: эти товары добавят — см. уточнение внизу.)
3. Ноль соцдоказательства на всём сайте — нет отзывов/рейтинга/«продано N»/прессы. [урок 5]
4. 2 из 4 категорий — тупики (Anti-Mite & Handheld, Floor Scrubbers в меню и плитках, товаров нет). (Гена: наполнят — см. уточнение.)
5. Мёртвые ссылки: футер и часть CTA → `/pages/contact`, `/pages/about` … = 404.

**Средне:**
6. Авто-карусель hero, 5 слайдов, смена 6 сек — слайды 2-5 почти никто не видит, движение мешает читать первый экран.
7. Текст блоками по 3 строки без списков/выделений (Innovations, описания) — теряется ~75% смысла. [урок 1]
8. Доставка 5-11 дней — прозрачно (не сюрприз, хорошо), но долго по меркам Amazon; возражение нигде не снимается.
9. Нет липкой кнопки/нижней панели «Shop» при скролле (в прототипе была `buybar`, не перенесли).
10. Нет сигналов безопасности у CTA (иконки оплаты, secure checkout, гарантия рядом с кнопкой). [урок 5]

**Мелко:**
11. Отступы секций 72-84px + крупные центрированные H2 → на мобильном страница ощущается очень длинной.
12. Глаголы в CTA разные: «Shop Vac Station» / «Shop the vacuum» / «Explore window robots».
13. Секция-разрез стоит глубоко — покупатель с интентом купить уйдёт раньше.
14. Порядок секций обслуживает «интерес», а не «покупку». Момент «вот товар, вот цена, вот кнопка» на главной не наступает.

### Вывод одним абзацем
Сайт сейчас — красивый бренд-лендинг, а не магазин: много визуала и воздуха, мало плотной информации, покупка на второй клик, товары в hero нельзя купить, доверять нечему (нет отзывов, есть 404 и тупики). Посетитель досматривает картинки и уходит.

## Часть 3. Рекомендации — что менять / добавить / убрать

### Главный сдвиг
За первые 1-2 экрана: что продаём → сколько стоит → кнопка купить → почему верить. Остальное — для дожатия.

### Рекомендуемый порядок секций главной
1. Hero — 1 статичный экран (не карусель), реальный флагман, цена, 2 кнопки (Shop / Learn)
2. Полоса ценности (есть) — доставка / возврат / гарантия / оплата
3. **Витрина товаров** — 4-6 реальных карточек: фото, цена, рейтинг, Add to cart
4. **Отзывы / рейтинг** — сразу после товаров, не в конце
5. Категории (плитки)
6. Innovations — переписать под сканирование
7. Разрез «Inside the machine»
8. Steps
9. FAQ
10. Футер
+ Липкая мини-панель «товар + цена + Shop» при скролле (моб. и ПК)

### ДОБАВИТЬ (по влиянию)
1. Витрина реальных товаров на главную (секция `glide-lineup` уже написана — вернуть и поднять выше). №1.
2. Блок отзывов (реальные, через Judge.me/Loox/Okendo; фейк запрещён).
3. Полноценный шаблон PDP (см. ниже).
4. Рейтинг-звёзды везде: hero, карточки, PDP. Даже «4.7 ★ · 120 отзывов».
5. Сигналы доверия у каждой «Купить»: иконки Visa/MC/PayPal/Apple Pay, secure checkout, 30-day returns.
6. Гарантия/возврат отдельным мини-блоком с иконкой рядом с товарами.
7. Страницы под ссылки футера: Contact, Shipping, Returns, About, Privacy/Terms/Refund.
8. Рабочий поиск в шапке (иконка есть).
9. Пояснение срока доставки там же, где он указан: «Ships from our EU/US warehouse in 5-11 days — free, fully tracked».
10. Липкая buy-bar при скролле.

### ИЗМЕНИТЬ
1. Hero: убрать авто-карусель 5 слайдов → 1 статичный (или max 3 без автопрокрутки). На слайде — реальный товар + цена + рейтинг.
2. Убрать пустоту в выделенной зоне: отступы секций 72-84px → ~40-48px; заголовки секций не по центру в 3 строки, а компактнее и левее, ближе к контенту.
3. Тексты под сканирование: заголовок = выгода, дальше 1 строка + 2-3 буллета с жирным первым словом. Не абзацы.
4. Единый паттерн CTA: везде «Shop <название>» или «Add to cart».
5. Поднять товары и отзывы выше по странице.
6. Меню: пункты только на заполненные коллекции (или сразу с товарами внутри).
7. Мобильный hero: явная подсказка листания (стрелка / полупоказ следующего слайда).

### УБРАТЬ / ПОЧИНИТЬ
1. Тупиковые категории — наполнить до запуска ИЛИ сделать некликабельными / «Coming soon».
2. Товары в hero, которых нет — добавить в каталог ИЛИ заменить на реальные.
3. Мёртвые ссылки `/pages/...` — создать страницы или скрыть ссылки.
4. Дубли в плитках (заголовок + «Shop X →») — оставить одно.
5. Лишний воздух между секциями.

### PDP — минимум
- Галерея 4-6 фото на белом + 1 в интерьере + короткое видео
- Название, цена, рейтинг с кол-вом отзывов, выбор варианта, Add to cart — всё выше сгиба
- Буллеты выгод (5-6, жирное первое слово)
- Таблица характеристик (размеры, мощность, площадь, время работы, что в коробке)
- Блок «What's in the box» с фото
- Доставка/возврат/гарантия на странице
- Отзывы внизу PDP
- Апселл: часто берут вместе / расходники

### Отзывы — как правильно
- Только реальные, через приложение с фото-отзывами (Judge.me / Loox / Okendo). Фейк запрещён и бьёт по доверию сильнее отсутствия.
- Показывать: рейтинг + количество под каждым товаром и в hero; 3-4 отзыва с фото на главной после витрины; полный список на PDP.
- Формат: имя, звёзды, короткий текст, фото, Verified purchase.
- Не прятать 4★/3★ — смесь оценок повышает доверие к 5★.

### Порядок работ
**Быстрые (часы, большой эффект):** витрина товаров на главную (секция готова) · срезать пустоту в выделенной зоне · hero → 1 статичный слайд с ценой · тупиковые категории некликабельными · иконки оплаты + secure checkout у кнопок.
**Средние (день-два):** блок отзывов + приложение · переписать тексты Innovations под буллеты · липкая buy-bar · страницы-заглушки футера с контентом.
**Большие (отдельная задача):** шаблон PDP · рабочий поиск · страницы линеек (line) под каждую категорию.
