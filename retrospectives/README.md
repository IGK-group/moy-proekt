# retrospectives/ — рефлексии после сессий

Рефлексия после каждой важной сессии. Формат файла: `YYYY-MM-DD_HH-MM_краткое-описание.md`

## Зачем

Клод в новом чате не помнит прошлое. Ты сам через неделю тоже не помнишь. Ретро — короткий файл, который можно прочитать за 30 секунд: что делал, что сработало, что нет, куда дальше. Клод читает последние ретроспективы перед новой задачей — это даёт контекст без лишних вопросов.

## Правила

1. Пишется после каждой сессии, где что-то решалось или строилось.
2. Имя файла: `YYYY-MM-DD_HH-MM_краткое-название.md`
3. Используй шаблон: [TEMPLATE.md](./TEMPLATE.md)

Правило записывать ретро в конце сессии уже прописано в `CLAUDE.md` — Claude делает это сам.
