### Важный вывод по 1688 фабрикам:
Флаг `dropship.enabled: true` = китайский внутренний дропшиппинг (代发), НЕ международный.
`isCrossBorderTrade: false` - фабрики не отправляют за рубеж напрямую.
Для Shopify US/EU нужен агент в Китае или использовать CJdropshipping.
CJdropshipping не показывает этих фабрик через API (они там есть, но поиск по API хуже чем интерфейс).
