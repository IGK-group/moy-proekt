# Ретро: полная обработка фото vacuum-ultrathin (7 слайдов, поэтапно с проверкой)

**Дата:** 2026-08-15 07:00
**Длительность:** ~2.5 часа

## 1. Задача

Обработать все 10 исходных фото vacuum-ultrathin в брендированные карточные слайды, работая слайд за слайдом с проверкой пользователем на каждом шаге (явное требование).

## 2. Как решал

1. Разобрал все 10 исходников через Read, сгруппировал по уникальности контента (нашёл дубли ракурсов, отсеял).
2. Проверил реальные варианты товара в Shopify (Black/White) и полное описание (features, комплектация) через Admin API - не полагался на память/предположения.
3. Делал по одному слайду, показывал ссылку на Drive, ждал подтверждения, только потом переходил к следующему.
4. Для композитных сцен (робот на трёх типах пола) сначала попробовал строгий контроль через PIL (вырезка + нарисованная тень) - не сработало визуально, робот "висел". Переключился на гибридный AI-подход: реальная вырезка робота + AI-сгенерированный пустой интерьер, оба переданы в `gpt_image_2` одним промтом с жёсткой инструкцией не перерисовывать робота - сработало убедительно.
5. Для "What's In The Box" сначала сделал честную, но примитивную инфографику (PIL-иконки нарисованы вручную геометрией) - пользователь справедливо назвал некрасивой. Пересобрал гибридно: PIL держит точные элементы (фото, типографика), AI (`gpt_image_2`) рисует только иконки в пустой области - результат сильно лучше.

## 3. Решил?

- [x] Да, полностью - 7/7 слайдов готовы, загружены на Drive, план обновлён.

## 4. Что можно было лучше

- На первой попытке слайда с полами сразу стоило пробовать AI-композит (реальный робот + сгенерированный интерьер одним промтом), а не начинать с ручного PIL-паста - потратил два цикла на тени, которые всё равно не убедили пользователя визуально.
- Для "What's In The Box" сразу стоило подумать "где сильна AI, где сильна точность" и сделать гибрид с первого захода, а не сначала делать целиком вручную примитивные иконки.
- При сборке слайда про цвета сразу открыть все кандидатные исходники (включая уже использованный `01.jpg`) вместо того чтобы полагаться на память о том, что в нём - ушёл один лишний цикл генерации на исправление.

## 6. Что не сработало

- Попытка 1 Hero-слайда: лайфстайл-фон (комната, шторы) → пользователь отклонил как "мутный, не презентабельный" → пересобран на чистом белом.
- Попытка 2 Hero-слайда: подпись AI разместила внизу слева, зацепилась углом за лого в правом нижнем углу → пересобран локально через PIL с подписью строго сверху отдельным блоком.
- Слайд с полами, попытка 1-2: ручной PIL-паст вырезанного робота + нарисованная тень (сначала простая, потом с точным расчётом контактной точки по alpha-маске) - оба раза пользователь справедливо заметил "висит в воздухе". Причина: перспектива фото робота (сверху под углом) не совпадает с ракурсом сцены, чисто геометрический паст этого не чинит.
- Слайд "What's In The Box", попытка 1: примитивные PIL-иконки (окружность, прямоугольники) - пользователь: "это не красиво".
