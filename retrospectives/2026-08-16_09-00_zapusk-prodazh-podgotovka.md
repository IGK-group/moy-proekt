# Ретро: снятие пароля, старт Google Shopping, план по тестовому заказу

**Дата:** 2026-08-16 09:00 (продолжение сессии со вчерашнего дня)
**Длительность:** ~1 час
**План:** `plans/2026-08-11-brending-i-oformlenie-magazina.md`, `plans/2026-08-09-cj-api-integration.md`

---

## 1. Задача

Убедиться, что магазин реально запущен (домен, пароль), составить план получения первых продаж, начать настройку Google Shopping.

## 2. Как решал

1. Проверил через API - домен подключён (`glidehomerobots.com`, SSL активен), пароль снят (`password_enabled: False`), витрина отвечает HTTP 200 напрямую.
2. Честно оценил готовность заявленного канала трафика (GeeLark контент-завод) - план `2026-07-18-kontent-zavod-polny-zapusk.md` на 0%, плюс частично устарел (писался под старую схему прямой оплаты фабрике, до пивота на CJ). Признал это открыто вместо того, чтобы направить пользователя на нереалистичный путь "сначала ферма, потом продажи".
3. Предложил два параллельных трека (быстрый - Google Shopping/ручной постинг, и долгий - GeeLark), пользователь выбрал быстрый.
4. Проверил товары на готовность к фиду Google Shopping - вес/категория есть, GTIN нет ни у одного варианта. Явно предупредил не выдумывать фейковый GTIN (политика Google, риск бана).
5. Провёл по шагам установку приложения Google & YouTube (только руками - OAuth-установка приложений недоступна через Admin API).
6. По запросу пользователя нашёл и объяснил штатный test mode Shopify Payments для тестового заказа без реальных денег - предупредил о побочном эффекте (пока test mode включён, реальные покупатели купить не могут) и посоветовал делать это сейчас, пока трафика ещё нет.
