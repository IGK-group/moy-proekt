# Ретро: наполнение магазина через CJdropshipping и настройка под запуск

**Дата:** 2026-08-09
**Длительность:** ~5+ часов (одна длинная сессия)
**План:** `plans/2026-08-09-cj-api-integration.md`

---

## 1. Задача

Наполнить MebelShop (`ghnjxs-hh.myshopify.com`) товарами из CJdropshipping для активного потока "гаджеты" (window cleaning robot, robot vacuum and mop), подключить фулфилмент и довести магазин до состояния "готов к первому реальному заказу".

## 2. Как решал

Установил CJ API-доступ (ключ -> access token), искал товары через `product/listV2`, проверял экономику через `unit_economics.py` (сначала с ROAS-моделью, потом переписал под органический CAC по указанию пользователя). Создавал товары сначала напрямую через Shopify Admin API - оказалось нерабочим решением (см. п.6). Пересоздал через нативный "List" флоу приложения CJ в браузере (руками пользователя, я только давал инструкции и проверял результат через API). Параллельно настраивал доставку, налоги, политики магазина, разобрался с реальной пошлиной США через подсказку в интерфейсе CJ и блог CJ.

## 3. Решил?

- [x] Частично — что сделано, что нет:
  - Сделано: 4 товара в магазине, все подтверждённо привязаны к CJ (аудит по SKU с обеих сторон), доставка США настроена и работает, международная зона существует (не проверена детально), пошлина прояснена (15% уже в цене доставки CJPacket Sensitive), все политики (Refund/Shipping/Terms/Privacy/Contact) заполнены и согласованы с реальными возможностями CJ (не обещаем возврат "передумал", которого CJ не поддерживает)
  - Не сделано: тестовый заказ (самое критичное - реально ли работает вся цепочка Shopify->CJ->отправка), Markets для Европы (сейчас включён только US), домен (только `.myshopify.com`), трафик (контент-завод не подключён)

## 4. Что можно было лучше

- Сразу проверять `productType` (ORDINARY_PRODUCT vs SUPPLIER_PRODUCT) у каждого кандидата ДО того, как тратить время на экономику/фото/описание - это сэкономило бы половину сессии на пылесосах
- Не создавать товары напрямую через Shopify Admin API в обход CJ вообще - сразу идти через нативный флоу приложения, раз цель - автофулфилмент, а не просто карточка в каталоге
- Искать в CJ сразу без `countryCode`/`verifiedWarehouse` фильтров - они прячут реальные товары на китайском складе почти полностью
- Проверить подсказку про 15% пошлину в интерфейсе CJ значительно раньше, а не после долгого чтения блогов/документации CJ, которые сами себе противоречат

## 5. Как было / как стало

- **Было:** CJdropshipping только что установлен, 0 товаров в магазине, доставка/политики/налоги не настроены, магазин фактически не готов принимать заказы
- **Стало:** 4 товара (2 ниши x 2 ценовых уровня), все с подтверждённой связью к CJ, честная экономика (~$35-100 прибыли/заказ в зависимости от товара), настроенная доставка США, заполненные политики под реальные возможности CJ, устранены задвоения расходов в модели прибыли

## 6. Что не сработало

- Попытка 1: создать товары напрямую через `POST /products.json` в обход CJ → выглядело рабочим (карточки создавались нормально), но CJ не видел эти товары в своём "My Products" (0 совпадений по SKU) - без этого не работает автофулфилмент. Пришлось удалить и пересоздать 4 товара через нативный флоу приложения.
- Попытка 2: связать CJ-товар с Shopify-карточкой напрямую через API (`product/conn/connection`) → нашёл эндпоинт, подтвердил 2 обязательных поля методом проб, дальше упёрся в недокументированную ошибку формата. Сознательно остановился - write-операция, определяющая маршрутизацию реальных заказов, рисковано гадать вслепую.
- Попытка 3: выбрать премиум/бюджетные пылесосы по качеству листинга и экономике (Yq16pro, Black Robot Vacuum Mop) → оба оказались `SUPPLIER_PRODUCT`, физически не находятся через "Add Product" в приложении, несмотря на легитимность самого товара. Пришлось искать замену через фильтр по `productType`.
- Попытка 4: искать "window cleaning robot" прямыми фразами → нерелевантная выдача (мойки окон, сигнализации). Сработало только без гео/verified-фильтров и с формулировкой "robot window cleaner".
- Попытка 5: доверять документации CJ (`developers.cjdropshipping.com`) насчёт пошлины → два блог-поста CJ сами себе противоречат ("включена в фрахт" vs "временно убрана из системы"). Реальный ответ нашёлся не в документации, а во всплывающей подсказке прямо в интерфейсе приложения ("15% уже включено").
