# Ретро: тестовый заказ пройден, поиск пути завести официальные соцаккаунты

**Дата:** 2026-08-16 11:00 (продолжение сессии)
**Длительность:** ~1.5 часа
**План:** `plans/2026-08-11-brending-i-oformlenie-magazina.md`

---

## 1. Задача

Провести тестовый заказ на живом магазине без реальных денег, начать подключение Google Shopping и официальных соцканалов (Facebook/Instagram/TikTok) к Shopify.

## 2. Как решал

1. Провёл пользователя через Shopify Payments test mode: включить → пройти чекаут на живой витрине тестовой картой Stripe (`4242 4242 4242 4242`) → подтвердил через API, что заказ #1001 создан с флагом `test: true`, оплачен, но НЕ ушёл в фулфилмент (значит CJ ничего не получил, реальные деньги не списаны) → выключить test mode.
2. Начал установку Google & YouTube канала - обнаружил, что установка приложений через Admin API недоступна (OAuth-флоу, только руками), провёл пользователя по интерфейсу (кнопка сменилась с ожидаемой "+" на "Shopify App Store" - актуальная версия интерфейса отличается от того, что я предполагал).
3. Пользователь захотел сразу и Facebook/Instagram/TikTok - разобрал по каждой площадке отдельно: выяснилось, что у пользователя только китайский номер (риск для Meta) и номер друга в Канаде (на нём уже есть личные FB+IG, отдавать которые друг не готов).
4. **Ключевая проверка вместо предположения:** перед советом "не делай второй аккаунт на тот же номер" проверил через веб-поиск актуальную политику Meta/Instagram, а не полагался на память - подтвердилось: Facebook действительно ограничивает один личный аккаунт на человека и коррелирует аккаунты по номеру/устройству/IP, Instagram официально разрешает несколько аккаунтов на номер. Дал разное решение под каждую площадку на основе этого, не единый совет.
5. Пользователь захотел попробовать купить готовые аккаунты вместо регистрации - честно предупредил про уже задокументированный в проекте риск (`payments-risks.md`, dark.shopping), но по запросу всё равно поискал альтернативы (PlayerUp, FameSwap) с оговоркой, что не могу поручиться за надёжность серого рынка. PlayerUp на практике оказался с пустыми/недоступными категориями, FameSwap не проверен до конца.

## 3. Решил?

- [x] Частично - что сделано, что нет:
  - Сделано: тестовый заказ пройден и подтверждён (это была основная техническая задача), разобран правильный путь для каждой соцплощадки отдельно (Page для FB, новый аккаунт для IG/TikTok), закрыт тупиковый путь покупки готовых аккаунтов для официального канала.
  - Не сделано: сама установка Google & YouTube канала (пользователь в процессе), сами Facebook Page/Instagram/TikTok аккаунты ещё не созданы физически - только определён план для каждого.

## 4. Что можно было лучше

- Когда пользователь несколько раз просил "дай ещё один ресурс" для покупки аккаунтов, стоило раньше остановиться и прямо предложить вернуться к честной регистрации - после первого неудачного (PlayerUp) уже было ясно, что это буксует, а не только после второго захода.

## 5. Как было / как стало

- **Было:** магазин публично живой, но чекаут ни разу не был реально проверен end-to-end; официальных соцканалов бренда не было вообще, пути их завести не было.
- **Стало:** чекаут подтверждён рабочим (реальный заказ, реальная оплата тестовой картой, без утечки в CJ-фулфилмент); для каждой соцплощадки есть конкретное, проверенное по актуальным правилам решение, что именно делать (не общий совет "заводи аккаунты", а по каждой площадке отдельно с учётом того, что реально есть под рукой у пользователя).

## 6. Что не сработало

- Попытка найти работающий маркетплейс готовых аккаунтов: `dark.shopping` (уже известный риск), `PlayerUp` (категории на практике пустые/недоступны, несмотря на то что поиск показывал рабочие tag-страницы), `FameSwap` (не доведено до результата). Ни один не дал пользователю купить аккаунт за этот отрезок сессии - решили не продолжать эту ветку, вернуться к обычной регистрации.
