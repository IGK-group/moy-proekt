# MebelShop - навигация по проекту

Интернет-магазин и маркетплейс мебели из Китая с доставкой по России, Беларуси, США и Европе.

Подробности - в `business/INDEX.md`.

## Стек

Shopify (витрина + заказы) + Claude Code API (автоматизация) + Higgsfield (генерация видеоконтента) + 1688/Taobao API (остатки и цены, планируется).

## Ключевые принципы работы

1. **Всегда читай `business/INDEX.md`** перед задачей, связанной с бизнесом. Не пиши тексты, не придумывай дизайн, не строй логику без контекста.
2. **Один чат - одна задача.** Закончил - закрой чат, открой новый.
3. **Ищи в `prompts/INDEX.md` до того как писать промпт с нуля.**
4. **План для каждой новой функции** - в `plans/YYYY-MM-DD-название.md`:
   - Разделение на фазы со статусами `[ ]` / `[x]`
   - В конце - итог: реализовано / что осталось
   - Актуализация плана после каждой сессии
5. **Ретроспектива в конце каждой сессии** - в `retrospectives/YYYY-MM-DD_HH-MM_название.md`:
   - Какая задача была
   - Как решал
   - Решил: да / нет / частично
   - Что можно было лучше
6. **Коммить только свои изменения.** Не используй `git add .` - стейджь файлы поимённо.
7. **Данные с коротким TTL** (цены, остатки, курсы) - в БД/конфиге, не в коде.

## Безопасность

- **Не скармливай Клоду:** паспорта, пароли, ПДн клиентов, ключи API.
- **`.env` не читай целиком** - только через `process.env.НАЗВАНИЕ` в коде.
- **Перед Bypass Permissions** - обязательный git-коммит.
- **Перед установкой любого скила / MCP** - аудит через `prompts/setup/08-skills-install.md`.

## Триггеры операционного планирования

| Фраза | Действие |
|---|---|
| «давай спланируем неделю» / «план на неделю» | Читай `business/goals/monthly.md` → создай `business/execution/YYYY-WNN.md`. Не больше 5 ключевых результатов. |
| «добавь задачу» / «запиши задачу» | На конкретный день - в файл недели. Без даты - в `business/execution/backlog.md`. |
| «что на этой неделе?» | Покажи файл текущей ISO-недели. |
| «итоги недели» / «закрой неделю» | Заполни секцию «Итог недели». |
| «перенеси X на следующую неделю» | Убери из текущей, добавь в следующую. |
