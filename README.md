# GlideHome — прототип витрины

Полный визуальный каркас витрины по **структуре** эталонной страницы смарт-хоум
(ECOVACS WINBOT / eufy / Roborock — отраслевой стандарт информационной архитектуры).
Копируется **концепция**: порядок и назначение секций, модель навигации, набор эффектов,
ритм макета. **Не копируются** чужие фото/видео/рендеры, точный шрифт, точные HEX и
рекламные тексты. Всё это — оригинальное GlideHome, помечено в CSS как `SWAP`.

Связано: `../plans/2026-09-01-redizayn-vitriny-pod-ecovacs.md`.

## Как смотреть

Открыть `index.html` в браузере (двойной клик / file://). Все страницы связаны ссылками.

| Файл | Что это |
|---|---|
| `index.html` | Главная: hero-ротация, плитки линий, видео-карусель, отзывы, награды, инновации, рассылка, футер |
| `line.html` | Посадочная товарной линии: статичный hero, карусель моделей, 4 блока инноваций, FAQ, explore |
| `product.html` | Карточка товара (PDP): галерея, цена, варианты цвета, добавить в корзину, характеристики, апселл-гарантия, отзывы, sticky buy bar |
| `support.html` | Центр поддержки: карточки разделов, FAQ, форма связи |
| `about.html` | О компании |
| `styles.css` | Общая дизайн-система. Токены `SWAP` — под замену первыми |
| `app.js` | Общие интерактивы (hero, scroll-reveal, аккордеон, слайдер отзывов, sticky bar) |
| `slides/` | Hero-слайды, сгенерированы в Higgsfield на наших товарах |

## Инвентарь эффектов (как у эталона, код свой)

Липкий хедер со сжатием на скролле · hero-ротация (~6 c, стрелки + точки с прогресс-заливкой,
пауза на hover) · горизонтальная карусель моделей со scroll-snap · scroll-reveal секций ·
FAQ-аккордеон (открыт один, «показать все») · слайдер отзывов со стрелками и автопрокруткой ·
hover-подъём карточек · sticky buy bar на мобильном.

## Разбор hero-слайдов эталона (концепция, не ассеты)

Наблюдаемая механика: 4 слайда, стрелки + индикаторы, автопрокрутка ~5–6 c, смена — плавное
затухание. Один слайд = один товар. Заголовок — имя товара. Фон — рендер/фото товара на чистом
светлом фоне, много воздуха, студийный или тёплый свет. Акцентный синий только на CTA.

**Четыре типа хука в подзаголовке:**

| Тип хука | Как звучит у эталона | Наш слайд |
|---|---|---|
| Запуск / срочность | «Launching Aug. 28» | (в запасе — под промо) |
| Категорийная заявка | «A Breakthrough in Robotic Window Cleaning» | Слайд 1 (W17S): «Чистые окна, пока вы заняты своими делами» |
| Соцдоказательство | «Trusted by Millions» | (в запасе — когда будут цифры продаж) |
| Уникальная фича | «The First … with FocusJet» | Слайд 2 (DYP): «Создан для панорамных окон. Без лестниц, без границ» |

**Требования Гены к слайдам (2026-09-01):** светлые тона, красивый дизайнерский интерьер,
большие/панорамные окна; товар реалистичен (стоит/присосан, не висит в воздухе), развёрнут
лицом к камере, выглядит ВКЛЮЧЁННЫМ; НЕ использовать эффект грязных окон.
