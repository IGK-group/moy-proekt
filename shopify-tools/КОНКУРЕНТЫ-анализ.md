# Поиск и анализ конкурентов - гайд

## Цель
Найти магазины которые продают те же товары (роботы-пылесосы, мойщики окон) и понять как они продают - откуда трафик, какие объявления, какой контент.

---

## Шаг 1 - Найти конкурента

**Через Google Shopping (DataForSEO):**
```bash
cd /home/claudeuser/moy-proekt
python3 shopify-tools/competition_check.py
```
Даёт список конкурентов на Amazon по нише.

**Вручную:**
- Google: `window cleaning robot site:shopify.com`
- Google Shopping: искать по ключевым словам
- Dropship.io ($29/мес) - специально для поиска дропшиппинг конкурентов

---

## Шаг 2 - Анализ трафика магазина

**Через наш store_tracker.py:**
```bash
python3 shopify-tools/store_tracker.py <домен конкурента>
```
Покажет: органический трафик, платная реклама, ключевые слова, whois.

---

## Шаг 3 - Найти их рекламу

**Facebook Ad Library (бесплатно, без регистрации):**
- Ссылка: `https://www.facebook.com/ads/library`
- Вводишь название бренда или домен
- Видишь ВСЕ активные объявления Facebook + Instagram
- Чем дольше крутят объявление - тем прибыльнее

**TikTok Creative Center (бесплатно):**
- Ссылка: `https://ads.tiktok.com/business/creativecenter`
- Поиск топ объявлений по нише

---

## Шаг 4 - Найти соцсети конкурента

1. Footer сайта - иконки Instagram/TikTok/Facebook
2. В объявлениях Ad Library - ссылка на их страницу
3. Google: `site:instagram.com "название бренда"`

---

## Что смотреть в их рекламе

- Формат видео (горизонталь/вертикаль, длина)
- Что говорят в тексте (оффер, скидка, бесплатная доставка?)
- Какие боли закрывают
- Сколько времени объявление активно (= прибыльность)
- Какой call-to-action

**Apify** - платформа для веб-скрапинга. Использовали для поиска фабрик на 1688.com.

**Актор который использовали:**
- Название: `zen-studio/1688-wholesale-scraper`

**Как запускали:**
1. Зайти на apify.com под аккаунтом gendosku@gmail.com
