# shopify-tools - инструменты для MebelShop

> Полный статус подключения, реальные данные магазина, как входить в админку - в [`PLAYBOOK.md`](./PLAYBOOK.md). Читай его первым, не этот файл.

Скрипты для синхронизации цен и остатков с магазина-донора.

## Как работает

```
Магазин-донор (публичный /products.json)
        ↓ парсим цены
MebelShop (Admin API) ← ставим цену * DISCOUNT + остатки
```

Любой Shopify-магазин отдаёт каталог без авторизации по `/products.json`.
Менять цены в своём магазине - только через Admin API токен.

## Скрипты

| Скрипт | Что делает |
|---|---|
| `get_token.py` | Получить/переполучить Admin API токен через OAuth |
| `set_inventory.py` | Выставить `TARGET_AVAILABLE` для ВСЕХ вариантов (первый запуск) |
| `update_prices.py` | Обновить цены всех товаров по донору |
| `update_new_products.py` | Обновить цены + остатки новых товаров за день |

Настройка `.env`, реальные переменные для MebelShop, пошаговый запуск - всё в `PLAYBOOK.md`.

## Важно

- Тестируй на 2-3 товарах сначала - скрипты меняют живой магазин
- `.env` не коммитить (уже в `.gitignore`)
- Встроенный retry на rate-limit (429) - не убирать
- `DISCOUNT` меняй в `.env`, не в коде
