# Контент-завод - точка входа

> Обращайся сюда, когда работаешь с производством контента, соцсетями или GeeLark-профилями - для любого магазина. Здесь собраны все знания по теме - не нужно заново перечитывать план или гуглить.

## Что это

Конвейер: сырое видео с фабрик в Китае -> обработка -> публикация на 5 платформах (TikTok/Instagram/Facebook/YouTube/Pinterest) через GeeLark-профили (виртуальные телефоны) -> Linktree -> Shopify.

**Важное разграничение доступа:** контент-завод работает через GeeLark (антидетект + US-прокси на каждый профиль, отдельно на каждую соцсеть) - это его собственный инструмент. AdsPower (профиль "store 1", Socks5 USA/NY) - отдельный инструмент, подтверждённо созданный для Shopify: магазин зарегистрирован и держится на этом прокси, GeeLark он не заменяет и к контент-заводу отношения не имеет. Подробности - `../shopify-tools/PLAYBOOK.md`. Подключение Claude к Shopify - через Admin API токен, без браузера вообще.

Почему это вообще важно для контент-завода: Гена - гражданин Беларуси, физически в Китае, а Shopify Payments недоступен мерчантам из Беларуси и настороженно относится к несовпадению страны аккаунта и IP (см. [`payments-risks.md`](./payments-risks.md)). Тот же класс риска (несовпадение гео) актуален и для GeeLark-профилей соцсетей - каждый профиль должен последовательно держать один и тот же US IP, не смешивать.

## Как контент-завод связан с остальными системами

```
Видео с фабрик (Гена в Китае)
        ↓ Higgsfield (обработка/генерация)
        ↓ Claude Cowork (производство текста: 1 сценарий -> посты/рилс/статья/тред)
        ↓ см. инструкции/claude-cowork-kontent-zavod.md
GeeLark-профили (виртуальные телефоны, US-прокси)
        ↓ публикация
TikTok / Instagram / Facebook / YouTube / Pinterest
        ↓ bio-ссылка
Linktree
        ↓ трафик
Shopify-магазин ghnjxs-hh.myshopify.com
        ↓ заказ -> Гена закупает у фабрики
```

| Система | Роль | Где настроено |
|---|---|---|
| Shopify (магазин) | Конечная точка продажи - куда идёт трафик с соцсетей | `../shopify-tools/PLAYBOOK.md` |
| Shopify Admin API | Claude читает/пишет в магазин без браузера | `../shopify-tools/PLAYBOOK.md` |
| AdsPower "store 1" | Вход в Shopify Admin через браузер (не для соцсетей) | `../shopify-tools/PLAYBOOK.md` |
| GeeLark | Виртуальные телефоны для соцсетей (не для Shopify) | `./architecture.md` |
| Higgsfield | Генерация/обработка видео для контента | `../ai-clone/reference/README.md` |
| ai-clone | Тон, голос, стоп-слова для всех текстов | `../ai-clone/INDEX.md` |
