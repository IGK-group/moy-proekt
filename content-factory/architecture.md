# Архитектура контент-завода

> Как устроен конвейер целиком - схема, инфраструктура, экономика. Пошаговые процедуры (регистрация, прогрев, публикация) - в [`playbook.md`](./playbook.md). Текущий факт-статус (что уже куплено/зарегистрировано) - в [`accounts.md`](./accounts.md). **Перед тем как платить за что-либо из таблицы ниже - прочитать [`payments-risks.md`](./payments-risks.md)** (Беларусь+Китай: санкции, крипта, 3-D Secure).

## Схема

```
Контент (видео с фабрик)
        ↓
3 профиля GeeLark (3 виртуальных телефона)
        ↓
5 платформ на каждом профиле: TikTok / Instagram / Facebook / YouTube / Pinterest
        ↓
Linktree (уникальный на каждый профиль)
        ↓
Shopify-магазин
        ↓
Продажа
```

Универсальная масштабируемая схема - работает для любого продукта и, при расширении, для любого магазина (см. [`multi-store-isolation.md`](./multi-store-isolation.md)).

## Инфраструктура

| Что | Где | Цена | Назначение |
|---|---|---|---|
| US IP (по одному на профиль) | IPRoyal | ~$5/шт | Гео для GeeLark-профиля |
| GeeLark Base | geelark.com | $5/мес | Виртуальный телефон, RPA-публикация |
| smspool.net баланс | smspool.net | ~$10 | SMS-верификация при регистрации соцаккаунтов |
| Facebook-аккаунт (готовый, с историей) | dark.shopping | $5-15/шт | Facebook не даёт регистрировать с нуля без чекпоинта - импорт через cookies |
| CapCut Pro | capcut.com | $10/мес | Монтаж, нарезка видео на клипы |
| Linktree | linktree.com | - | Точка перехода соцсеть -> Shopify, по одному на профиль |

**Email:** ProtonMail, западные имена (не шаблонные), формат `[имя].store@proton.me`, отдельный на профиль.

**Настройки GeeLark-профиля:** язык English (United States), таймзона America/New_York, ОС Android (последняя версия), свой US IP на профиль.

## Финансовая модель

### Расходы

Разовые на старт: $40-70. Ежемесячные: $97-109 (3 US IP $15 + GeeLark $30-40 + smspool $3-5 + CapCut $10 + Shopify Basic $39).

### Юнит-экономика (1 заказ, средний чек $300)

Выручка $300 -> себестоимость товара -$120 (40%) -> доставка Китай-US -$40 (13%) -> возвраты/брак 5% -$15 -> Shopify-комиссия 2.9% -$9 -> доля инфраструктуры -$10 (3%) -> **чистая прибыль $106 (35%)**.

CAC (органика) ~$10 · LTV (2 покупки) $212 · LTV/CAC 21x.

### Точка безубыточности

2-3 заказа в месяц при чеке $300 - инфраструктура окупается.
