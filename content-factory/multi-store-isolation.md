# Мульти-магазинная изоляция контент-завода

> Синтез из планирования мульти-магазинной системы Shopify (2026-07-25). Полный план на паузе, лежит вне репозитория в `/home/claudeuser/.claude/plans/staged-brewing-possum.md` (см. память `project-multi-store-plan`). Актуально только на будущее - сейчас у Гены один магазин (MebelShop), но принцип зафиксирован здесь заранее, чтобы не изобретать заново, когда магазинов станет больше.

## Принцип

Гена решил: каждый новый Shopify-магазин - **отдельный аккаунт**, не общий Partner-аккаунт, чтобы блокировка одного не задела остальные. Тот же принцип нужно применить и к контент-заводу: свой набор GeeLark-профилей / прокси / соцаккаунтов под каждый магазин.

## Что это значит технически, когда появится больше одного магазина

- **Синхронизация каталога** в соцсети - без кода: через встроенные Shopify Sales Channels (Facebook & Instagram, TikTok, Google & YouTube) - официальные приложения в самой Shopify-админке, ставятся на аккаунт конкретного магазина. Не отдельная интеграция, тот же паттерн, что установка CJdropshipping/DSers.
- **Рекламные и соц-аккаунты** (Meta Business Manager, VK Ads, TikTok Business) заводятся отдельно под каждый магазин - не шарятся между магазинами.
- **Контент** (посты, подписи, сценарии) для конкретного магазина Claude берёт из собственных файлов этого магазина - `business/assets/copy-bank.md` + `business/assets/brand-guidelines.md` + `business/audience/avatar.md`. В мульти-магазинной архитектуре это будет `stores/<slug>/business/...` вместо корневого `business/` (MebelShop остаётся особым случаем в корне - решение зафиксировано в паузнутом плане).
- **Higgsfield** (когда подключат) и любой другой генератор контента - привязывается по тому же принципу: параметризация slug'ом магазина, не хардкод на MebelShop.
- `accounts.md` в этой папке уже структурирован с заголовком-секцией на магазин ("Магазин: MebelShop") - при добавлении нового магазина туда добавляется новая секция, а не отдельный файл.

## Что сознательно не строим заранее

Код под конкретные рекламные/соц API (Meta Marketing API, VK Ads API и т.п.) - ни один канал ещё не подключён, автоматизация неоправданна при темпе 2-3 магазина/месяц. Когда решится, какой канал автоматизировать первым - отдельный план по схеме `shopify-tools/`: скрипт, параметризованный `STORE=<slug>`, credentials в `stores/<slug>/.env`.
