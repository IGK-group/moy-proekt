2. **"What Is a Cloud Phone?"** (geelark.com/blog/what-is-a-cloud-phone) - база для новичка
3. **"Cloud Phone for TikTok: Complete Beginner's Guide"** (geelark.com/blog/cloud-phone-for-tiktok) - платформенный гайд, TikTok - один из 5 каналов плана
4. **GeeLark RPA Guide for Beginners (серия 2/4/5)** (geelark.com/blog/geelark-rpa-guide-*) - официальная документация no-code RPA-конструктора: тапы/скроллы/ожидания/циклы/условия - нужно для Фазы 4 (автопубликация)
5. **"Automate Social Media Posts: A Guide for Brands and Creators"** + **"How to Build TikTok Bots with RPA"** - официальные гайды по автоматизации прогрева/публикаций/вовлечения

## Ключевой практический факт для нашего плана

GeeLark даёт реальный Android cloud phone (настоящий IMEI, MAC, данные сенсоров) - не эмуляцию, поэтому не палится мобильными платформами так, как обычный антидетект-браузер на десктопе. В 2026 году добавлена AI-автоматизация (модели вроде DeepSeek) для имитации поведения. Ограничение: только Android, iOS-фингерпринтов нет. Оплата - строго по минутам использования (pay-as-you-go), при исчерпании баланса workflow останавливается полностью - держать баланс с запасом, не впритык.
