# Плейбук контент-завода

> Пошаговые процедуры: регистрация профиля, прогрев, производство и публикация контента. Общая архитектура и инфраструктура - в [`architecture.md`](./architecture.md). Прогресс отмечай в [`accounts.md`](./accounts.md), не здесь - этот файл про "как", не про "что уже сделано".

## Модель риска: что реально палит мультиаккаунтинг

Несколько своих аккаунтов, ведущих на один свой Shopify-магазин - **не риск сам по себе**, так работает любой легальный бренд с присутствием на нескольких площадках. Не нужно прятать/маскировать ссылку на магазин - прямая ссылка в bio (через Linktree) легитимнее, чем что-либо замаскированное.

Реальные факторы риска - три, и ни один не про саму ссылку:

1. **Купленные Facebook-аккаунты (dark.shopping)** - риск встроен в актив ещё до публикаций, история смены владельца детектится независимо от контента.
2. **Повторяющийся контент между профилями** - хэширование видео (см. правило ниже про уникальный файл на каждый аккаунт).
3. **Нестабильный IP/фингерпринт профиля** - каждый GeeLark-профиль держит один и тот же US IP постоянно, смена прокси у профиля подозрительнее, чем совпадение конечного домена у разных профилей.

Защита - не в скрытии перехода на магазин, а в том, чтобы профили реально вели себя как независимые: разный контент, стабильный IP, разное время публикации (всё ниже по плейбуку).

## Регистрация профиля

Делается последовательно: сначала полностью закрываешь Профиль 1, потом Профиль 2, потом Профиль 3.

### День 1 - Pinterest
GeeLark профиль -> Браузер -> pinterest.com -> Sign up -> Continue with email -> proton email -> Интересы: Home Decor / Furniture / Interior Design -> Settings -> Convert to business -> Retail -> добавить сайт Shopify (верификация через мета-тег). Проблем обычно нет, телефон не нужен.

### День 2 - Instagram
GeeLark -> установить Instagram -> Create account -> Sign up with email -> proton email -> пароль -> username (нейтральный) -> дата рождения 1988-1995 -> код из ProtonMail.
Возможная проблема: через 1-3 дня просит номер -> smspool.net -> USA -> Instagram -> Mobile -> $1-2.

### День 3 - YouTube/Google
GeeLark -> Браузер -> accounts.google.com -> Создать аккаунт -> Для личных целей -> имя (западное) -> "Использовать существующий email" -> proton -> пароль -> дата рождения 1988-1995.
Возможная проблема: почти всегда просит номер в облачной среде -> smspool.net -> USA -> Google -> Mobile -> $1-2.
После создания Google - открыть YouTube, войти, создать канал.

### День 4 - TikTok
GeeLark -> установить TikTok -> Зарегистрироваться -> Email -> proton email -> дата рождения 1988-1995 -> пароль -> код из ProtonMail.
Возможная проблема: может не дать выбрать email или попросить номер позже -> smspool.net -> USA -> TikTok -> Mobile -> $1-3 (пробовать 2-3 номера, если первый не проходит).
После регистрации - ничего не заполнять, закрыть.

### День 5 - Facebook
НЕ регистрировать с нуля - Facebook даёт чекпоинт с фото документов в течение 7 дней. Импортировать купленный аккаунт (dark.shopping) через cookies в GeeLark: профиль -> установить Facebook -> импорт cookies -> аккаунт открывается залогиненным.

## Прогрев (14 дней, руками - не RPA)

Правило: никаких публикаций до конца 14 дней.

| День | TikTok | Instagram | Pinterest | YouTube | Facebook |
|---|---|---|---|---|---|
| 1-2 | Лента 20 мин | Лента 15 мин | Пины 10 мин | Видео 10 мин | Лента 10 мин |
| 3-5 | +10-15 лайков | +10 лайков | +сохранения пинов | +лайки | +лайки |
| 6-8 | +5 подписок +2 комментария | +5 подписок | +подписки на доски | +подписки | +3-5 подписок |
| 9-11 | +bio +фото профиля | +фото +bio | +первая доска | +оформление канала | +фото профиля |
| 12-14 | +ссылка Linktree в bio | +ссылка Linktree | +верификация сайта | +описание канала | +ссылка в профиле |

## Производство контента (конвейер на одно видео)

5-10 мин съёмки на фабрике/с товаром -> CapCut: нарезать на 5 коротких клипов (15-60 сек) -> для каждого профиля уникальная версия (менять порядок кадров/скорость/обложку/звук). **Нельзя один и тот же видеофайл на разные аккаунты - платформы хэшируют видео, идентичный файл на 3 аккаунтах = групповой бан.**

Подписи: Claude пишет 5 разных вариантов на английском, тон - `../ai-clone/voice/tone.md` + `vocabulary.md` + `stop-words.md`, аудитория - `../business/audience/avatar.md`.

Публикация: GeeLark RPA публикует по расписанию -> Pinterest: лучшие кадры адаптировать в статичные пины -> YouTube: лучшее видео - вручную 1 раз в день.

## Расписание публикаций (Eastern Time, US-аудитория)

- TikTok: 07:00 / 12:00 / 19:00 ET
- Instagram: 08:00 / 13:00 / 20:00 ET
- Pinterest: в любое время (контент живёт 12-24 мес)
- YouTube: 17:00 ET (1 раз в день)
- Facebook: 09:00 / 18:00 ET

GeeLark RPA выставляется один раз и работает автоматически.

## Масштабирование

Критерий: 20+ органических заказов за месяц с одного набора профилей.

Как: добавить ещё 3 профиля GeeLark (та же регистрация + прогрев, разные US IP). Один Shopify - несколько контент-потоков (разные профили под разные категории товара, например мебель / декор / текстиль).

Платный трафик - только после 20+ органических заказов, не раньше:
```
Личный Facebook (создан через US-прокси)
        ↓
Meta Business Manager
        ↓
Instagram-аккаунт из GeeLark
        ↓
Виртуальная карта (Capitalist) - оплата рекламы
        ↓
$5-10/день тестовый бюджет
```
