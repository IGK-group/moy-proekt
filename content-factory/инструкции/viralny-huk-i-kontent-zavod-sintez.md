Изучены два видео из папки `gdrive:SKILL/материал/`:
- **«Контент завод 2»** (Георгий Ривера, рус.) - про автоматизацию через Cowork
- **«Claude + Instagram Makes $100k/m Viral Dropshipping Videos»** (англ., ~28 мин) - про стратегию вирусных хуков + Instagram

Уроки разные по теме, но дополняют друг друга: первый про **как производить контент автоматически**, второй про **какой именно контент делать чтобы он вирусился**.

## Урок 1: «Контент завод 2» - ключевые выводы

Это продолжение первого урока (его у нас нет в материалах - там собирался контент-завод как проект в Claude Chat).

**Что показывает:**
1. Создаёшь локальную копию проекта (файлы скиллов, брендбук, инструкция) в папке на ноутбуке
2. Создаёшь папку «Новый сценарий» внутри
3. В Cowork подключаешь эту папку как проект
4. Создаёшь повторяющуюся задачу (ежедневно в 12:00) с мастер-промтом

**Что происходит каждый день:**
- До 12:00 - кладёшь транскрипт/сценарий в папку «Новый сценарий»
- Cowork запускается, читает файл, прогоняет через цепочку скиллов
- Создаёт 4 типа файлов: посты для соцсетей, сценарий для рилса, статья, треды
- Ноутбук должен быть включён и не в режиме сна

**Важное ограничение:** ноутбук/ПК должен быть включён в момент запуска. Это значит Cowork - не облачная автоматизация, а локальная. Для тебя это нерелевантно - ты работаешь на сервере через Claude Code, у нас другое решение (см. `claude-code-kontent-zavod.md`).

**Вывод по этому уроку для нас:** логика правильная (папка с сырьём → автоматическая обработка → 4 формата на выходе), но Cowork заменяем на Claude Code. Уже реализовано в `claude-code-kontent-zavod.md`.

## Урок 2: «Claude + Instagram $100k/m» - ключевые выводы

Это отдельная стратегия, не связанная с Cowork. Автор - английский дропшиппер, показывает реальные кейсы.

### Главная стратегия

**Органический Instagram/TikTok без рекламы:**
- Находишь практичный товар с утилитарной функцией (решает конкретную проблему)
- Снимаешь AI-видео на 8-10 секунд в качестве хука (история, ситуация)
- Склеиваешь с реальными демо-видео товара
- Постишь органически → вирус → трафик в Shopify

**Реальные цифры из видео:**
- Instagram-аккаунт «Nomad Gear Tools» - 9 000 подписчиков, одно видео собрало **6,3 млн просмотров**
- Другие ролики на том же аккаунте: 84K, 18K, 26K просмотров
- Товар: вакуумный насос для сжатия вещей в чемодане
- Продаёт через Shopify-магазин (ссылка в профиле)

### Формат который работает

**НЕ работает (хуже):** полностью AI-видео от начала до конца.

**РАБОТАЕТ:** AI-хук (8-10 секунд) + реальное демо товара.

```
[0-10 сек] AI-хук: история/ситуация, создаёт интригу
[10-60 сек] Реальные видео: демонстрация товара в действии
[финал] CTA: ссылка в профиле
```

Почему именно так: платформы детектируют полностью синтетический контент. Смешанный формат - оптимальный баланс.

**Лайфхак про опечатки в AI-видео:** намеренно не исправлять орфографические ошибки в тексте на AI-видео - они генерируют комментарии («у тебя ошибка!»), что увеличивает вовлечённость. Алгоритм видит активность и продвигает видео дальше.

### Психологические триггеры для хуков

Автор называет 6 типов хуков, которые останавливают скролл:

| Тип | Описание | Пример из видео |
|---|---|---|
| **Любопытство** | Что-то непонятное, хочется досмотреть | ? |
| **Потеря / страх потери** | Покажи что можно потерять без продукта | Девушка в аэропорту платит $100 за перевес |
| **Идентичность** | Это про меня, я такой человек | Путешественник с carry-on |
| **Нарушение паттерна** | Что-то неожиданное, шокирующее | Мужик засовывает голову в морозилку в магазине |
| **Социальное трение** | Неловкая ситуация, embarrassment | Мужик разбирает чемодан прямо на полу аэропорта |
| **Заговор** | Тебя кто-то обманывает / скрытая угроза | Карты могут быть считаны без ведома владельца |

Лучшие хуки - комбинируют несколько триггеров одновременно.

### Примеры AI-хуков из видео (переводы)

| Товар | Хук |
|---|---|
| Вакуумный насос | Дама, ваш багаж негабаритный - заплатите $100. «Подождите, не нужно...» |
| RFID-чехол | Кто-то пытается украсть данные карты в аэропорту - но карты защищены |
| Шейный вентилятор | Мужик в 45° жару засовывает голову в морозильник в магазине, потом достаёт вентилятор |
| Bluetooth-колонка | Роняют колонку в воду - IPX5, ей всё равно, продолжает играть |
| Робот-пылесос | Жена обнаруживает мужа в акваланге чистящего бассейн - «есть робот для этого» |
| Весы для чемодана | Мужик разбирает чемодан прямо в очереди на стойке регистрации |
| Очки с камерой | Пропустил момент из-за телефона - «я уже снял на очки» |

**Паттерн всех хуков:** показываешь проблему/боль в экстремальной или смешной форме → продукт решает её элегантно.

### Инструменты из видео

| Инструмент | Роль | Наш эквивалент |
|---|---|---|
| Claude (с промтом-«сотрудником») | Генерирует концепцию хука + промт для видео | Claude Code (мы и есть) |
| TopView.ai / Seedance 2.0 Omni Reference | Генерирует AI-видео по промту + фото товара | **Higgsfield** (у нас есть, Seedance 2.0 тоже там) |
| Instagram | Органическая публикация | GeeLark-профили в плане |

**Важно:** автор использует Seedance 2.0 Omni Reference - это та же модель что доступна в Higgsfield. То есть весь стек полностью воспроизводим.

### Параметры генерации видео (Seedance 2.0 Omni Reference)

- Формат: 9:16 (вертикальный)
- Длина: **10 секунд** (только хук)
- Режим: Omni Reference (даёшь фото товара + текстовый промт → он генерирует видео)
- 1 кредит = 1 секунда видео → 10 секунд = 10 кредитов

### Рабочий процесс создания одного хука

```
1. Найти товар с чёткой утилитарной функцией
2. Собрать: описание товара + 3-5 фото (с продукт-страницы поставщика/Amazon)
3. Дать Claude: описание + фото → запросить концепцию хука + готовый промт для видео
4. Загрузить в Higgsfield (Seedance 2.0 Omni Reference):
   - Фото товара как reference image
   - Промт из шага 3
   - Формат: 9:16, 10 секунд
5. Получить AI-хук видео
6. Склеить с реальными демо-видео товара (с AliExpress/1688 или снятые самостоятельно)
7. Опубликовать через GeeLark-профиль на Instagram/TikTok
```

## Применение к MebelShop

### Товары которые подходят под эту стратегию

Мебель из Китая - широкая категория. Лучше всего под вирусный формат идут:
- Компактная/трансформируемая мебель (стол-кровать, диван-трансформер, складной стул)
- Умные решения для хранения (полки с неожиданным механизмом, органайзеры)
- Вещи которые решают раздражающую бытовую проблему

Плохо подходят: статичные предметы (обычный стол, стандартный диван) - сложно показать «вау-момент».

### Примеры хуков для мебели (по аналогии)

| Товар | Идея хука |
|---|---|
| Стол-кровать | Гость внезапно приходит ночевать, у тебя «нет места» - раскладываешь стол в кровать за 10 сек |
| Складной стул | Очередь на концерте, все стоят устав - достаёшь карманный стул |
| Органайзер для кабелей | Ужас под столом - 30 проводов → один органайзер, всё чисто |
| Вакуумный контейнер для хранения | Огромная куча одеял - засовываешь в контейнер, нажимаешь кнопку - в 5 раз меньше |

### Где брать реальные демо-видео

1. Страницы товаров на 1688/Taobao - там часто есть видео-демонстрации от фабрики
2. AliExpress - продавцы обязательно загружают видео
3. Amazon - product videos на карточке товара
4. Гена физически в Китае - может снять видео прямо на фабрике (это уникальное преимущество)

## Промт для Claude: генерация хука

Используй в Claude Code когда нужно создать хук для конкретного товара:

```
Ты эксперт по вирусным хукам для короткого видео (Instagram Reels / TikTok).

Товар: [название товара]
Описание и функция: [что делает, какую проблему решает]
Целевая аудитория: покупатели мебели и товаров для дома из США/Европы

Задача:
1. Определи лучший тип хука из: любопытство / страх потери / идентичность / нарушение паттерна / социальное трение / заговор
2. Напиши концепцию хука: конкретная ситуация/история 8-10 секунд, где проблема показана в экстремальной или смешной форме, а продукт решает её элегантно
3. Напиши готовый промт для Higgsfield (Seedance 2.0 Omni Reference): опиши сцену детально - персонаж, обстановка, действие, эмоция, переход к продукту. Язык - английский. Формат 9:16, 10 секунд.
4. Укажи: какое фото товара лучше всего подать как reference image (угол, фон, кадр)

Голос - нейтральный английский для US/EU рынка. Никакого AI-флёра в описании сцены.
```

## Связь с остальным контент-заводом

```
Хук (AI-видео 10 сек, Higgsfield)
        +
Реальное демо товара (с 1688 / фабрика / Гена снимает)
        ↓ монтаж
Готовое видео 30-60 сек
        ↓ текст через конвейер скиллов (claude-code-kontent-zavod.md)
Подписи под Instagram + TikTok + Telegram + YouTube
        ↓ публикация
GeeLark-профили → Linktree → Shopify
```

Хук - это только первые 10 секунд. Остальное производится обычным конвейером.
