# Контент-завод в Claude Code - инструкция

Адаптация инструкции Георгия Ривера под реальный стек: сервер + VS Code + Claude Code.
Исходники скиллов лежат в [`../материал/SKILL-source/extracted/content-system/skills/`](../материал/SKILL-source/extracted/content-system/skills/).
Оригинальная Cowork-версия сохранена в [`claude-cowork-kontent-zavod.md`](./claude-cowork-kontent-zavod.md) как справочник.

## Чем отличается от Cowork-версии

| Cowork | Claude Code (VS Code + сервер) |
|---|---|
| Плагины-скиллы, `/команды` | Claude Code читает SKILL.md файлы напрямую с сервера |
| Локальная папка на твоём ноутбуке | Папки уже на сервере - ничего синхронизировать не нужно |
| Брендбук в проекте Cowork | Брендбук уже есть: `ai-clone/voice/` + `business/audience/avatar.md` |
| Планировщик задач в интерфейсе | Ручной запуск в Claude Code / cron на сервере |
| Connectors (Figma, Canva, Gamma) | Нет аналога, этот блок пропускаем |
| Безопасность аккаунта Cowork | Не актуально - всё на сервере, бекапы через git + Google Drive |

## Это другой слой, чем GeeLark-завод

В `content-factory/INDEX.md` описан конвейер: **видео с фабрик -> обработка -> публикация через GeeLark-профили -> Linktree -> Shopify**. Эта инструкция - про звено **«производство текста»**: как одну единицу сырья (транскрипт, сценарий, история) превращать в несколько готовых форматов (посты, сценарий рилса, статья, тред).

GeeLark - слой **дистрибуции**. Этот «завод» - слой **производства**. То, что здесь сгенерировано, редактируешь и отдаёшь в GeeLark-профили на публикацию.

## Часть 1. Настройка один раз

### 1.1 Структура папок на сервере

Создай папки (Claude Code сделает по команде):

```
content-factory/production/
├── input/          <- кладёшь сырьё перед запуском конвейера
└── output/
    └── YYYY-MM-DD/ <- готовый контент по датам
        ├── посты.md
        ├── сценарий-рилса.md
        └── статья.md
```

Создать прямо сейчас: скажи в Claude Code «создай папки production/input и production/output».

### 1.2 Брендбук - уже готов, дополнить

В Cowork нужно было заполнять брендбук отдельно. В Claude Code он уже есть в репозитории:

- **Голос и тон** - `ai-clone/voice/tone.md`
- **Лексика** - `ai-clone/voice/vocabulary.md`
- **Стоп-слова** - `ai-clone/voice/stop-words.md`
- **Аудитория** - `business/audience/avatar.md`
- **Продукт** - `business/products/overview.md`

Claude Code читает эти файлы автоматически при запросе «запусти конвейер» - дополнительно ничего делать не нужно.

## Часть 2. Ежедневный цикл

### Ручной режим (основной)

1. **Положи сырьё** - транскрипт видео с фабрики, история клиента, факт о товаре - в `content-factory/production/input/[название].md`, ИЛИ просто вставь текст прямо в чат Claude Code.

2. **Запусти конвейер** - одна из команд:
   - «Запусти контент-конвейер для файла [название]»
   - «Запусти контент-конвейер» (если вставил сырьё в чат)
   - «Запусти только разведчика в режиме История» - если нужен один шаг

3. **Claude Code сам:**
   - Читает сырьё и нужные SKILL.md файлы
   - Прогоняет через цепочку шагов
   - Сохраняет результат в `production/output/YYYY-MM-DD/`
   - Отчитывается что создано и где лежит

4. **Проверь результат** - это обязательный шаг, не опция.

5. **Публикация - только вручную.** Все платформы детектируют автопостинг - он убивает аккаунт.

6. Удали сырьё из `input/`, положи следующее.

### Полуавтоматический режим (на будущее)

Cron на сервере запускает Python-скрипт, который обращается к Claude API с мастер-промтом и читает файл из `input/`. Реализовывать когда ручной режим уже отлажен и понятно что производить. Скажи «реализуй автозапуск конвейера через cron» - сделаю.

## Часть 3. Мастер-промт конвейера

Оригинальный промт Ривера («ПРОМТ ДЛЯ КОНТЕНТ-ЗАВОДА»), адаптированный под MebelShop и Claude Code.
Полный оригинал лежит в `../материал/SKILL-source/ПРОМТ ДЛЯ КОНТЕНТ-ЗАВОДА.md`.

**Что производит:** 21 единица контента из одного сценария за один запрос:
- 1 статья (для блога / VC.ru / Дзен)
- 10 тредсов (Threads / Twitter)
- 5 сценариев рилсов (Instagram / TikTok / YouTube Shorts)
- 5 текстовых постов (Telegram / Instagram / YouTube)

Скопируй и вставь в Claude Code. Подставь сырьё в конец.

```
Ниже - финальный сценарий / транскрипт / история для MebelShop.
Твоя задача - размножить его на 21 единицу контента для всех платформ.
Делай всё за один раз. Не сокращай, не пропускай блоки. Каждая единица - копипаст-готовая.

Перед началом изучи сырьё и определи:
- Кто аудитория (читай business/audience/avatar.md)
- Какой разговорный регистр использует автор (голос - ai-clone/voice/tone.md, vocabulary.md)
- Какая основная проблема раскрывается
- Какие личные истории и кейсы приводятся
- Какой философский или ценностный слой заложен

Сохрани голос MebelShop во всех текстах. Стоп-слова - ai-clone/voice/stop-words.md.

ОБЯЗАТЕЛЬНЫЕ ПРАВИЛА ДЛЯ ВСЕХ ТЕКСТОВ:
- Сохраняй разговорный регистр: сленг, обороты, характерные выражения из ai-clone/voice/
- Обращение к аудитории - на «ты» (US/EU покупатели мебели)
- Антиии-фильтр на каждом тексте: никаких «стоит отметить», «необходимо подчеркнуть»,
  деепричастных оборотов-пустышек, канцелярита, отрицательных параллелизмов «не просто X а Y»,
  промо-языка (непревзойдённый, захватывающий дух), хеджирования (можно предположить)
- Финальный антиии-проход: перед каждым текстом спроси «что здесь выдаёт ИИ?» и перепиши

БЛОК 1. СТАТЬЯ (для блога / VC.ru / Medium)
Объём: 1500-2500 слов.
1) Заголовок по формуле ВИСП (Выгода + Интрига + Срочность + Причастность). Два варианта.
2) Лид (первые 2 предложения) - хук из сырья, адаптированный под текст. Зацепить за 3 сек.
3) Постановка проблемы - одна проблема. Усугубление: что будет если не решить?
4) Основная часть - 3-5 подзаголовков. Каждый: боль → пример → решение.
5) Философский блок - если в сырье есть притча/метафора/ценностный посыл - вынеси отдельно.
6) Заключение + CTA - подписаться / перейти в Shopify.

БЛОК 2. ДЕСЯТЬ ТРЕДСОВ
Каждый - самостоятельная микроединица. 3-7 предложений (до 500 знаков).
Строка 1: хук - вопрос, провокация, цифра или личный опыт.
Строки 2-5: одна мысль, один инсайт. Конкретика: цифры, названия, примеры.
Последняя строка: CTA (чередуй: подписка / сохранить / комментарий / канал).
Темы 10 тредсов: главный инсайт, статистика/цифра, ошибка аудитории, лайфхак,
личная история, до/после, философская мысль, разрушение мифа, чек-лист, провокация.

БЛОК 3. ПЯТЬ СЦЕНАРИЕВ ДЛЯ REELS / TIKTOK / YOUTUBE SHORTS
Хронометраж: 30-60 секунд (80-150 слов).
0-3 сек: хук-стоппер. 3-7 сек: боль зрителя. 7-25 сек: решение + конкретика. 25-30: CTA.
Режиссёрские пометки в скобках: (СМОТРИТ В КАМЕРУ), (ПОКАЗЫВАЕТ ТОВАР), (ПАУЗА).
Темы: главный инсайт, ошибка + правильный подход, лайфхак пошагово, история, философия.

БЛОК 4. ПЯТЬ ТЕКСТОВЫХ ПОСТОВ для Telegram / Instagram / YouTube
Объём: 500-1000 знаков. Чистый текст.
Строка 1: опенинг-хук. Строки 2-6: одна мысль, разговорный стиль, короткие абзацы. Финал: CTA.
Темы: анонс с интригой, инсайт + личное мнение, кейс/пример, философская мысль, вовлечение.

АНТИИИ-ЧЕКЛИСТ ПЕРЕД ВЫДАЧЕЙ:
[ ] Нет «стоит отметить», «необходимо подчеркнуть», «в рамках», «данный»
[ ] Нет деепричастных оборотов-пустышек
[ ] Нет группировки всего по три
[ ] Нет «не просто X, а Y»
[ ] Нет промо-языка (непревзойдённый, захватывающий дух)
[ ] Нет хеджирования (можно предположить, что)
[ ] Разговорный регистр MebelShop сохранён
[ ] Текст звучит естественно при чтении вслух

ФОРМАТ ВЫДАЧИ - ЧЕТЫРЕ ФАЙЛА:
Сохрани в content-factory/production/output/[сегодняшняя дата]/:
- Статья_[краткая тема].md
- Тредсы_[краткая тема].md (10 тредсов, каждый отделён ---)
- Рилсы_[краткая тема].md (5 сценариев с хронометражем и пометками)
- Посты_[краткая тема].md (5 постов, каждый отделён ---)

После сохранения выведи сводку: какие файлы созданы, сколько единиц в каждом,
список тем/хуков для быстрого просмотра.

Приступай. Сырьё ниже:
[ВСТАВЬ СЮДА ТРАНСКРИПТ / СЦЕНАРИЙ / ИСТОРИЮ]
```

## Часть 4. Цепочка скиллов - справочник

Скиллы лежат в `../материал/SKILL-source/extracted/content-system/skills/[название]/SKILL.md`. Claude Code читает их когда ты называешь скилл по имени.

| # | Скилл | Папка | Когда вызывать |
|---|---|---|---|
| 1 | Директор | `director/` | Начало сессии, проверка: работает ли идея на цель (продажи) |
| 2 | Разведчик | `scout/` | Достать углы из сырья - режимы «Сигнал» / «История» / «Вопросы» |
| 3 | Архитектор | `youtube-pro/` | Идеи и структура для длинных YouTube-видео |
| 4 | Хук-мастер | `hook/` | Открытие от кульминации для любого формата |
| 5 | Сценарист | `reels/` | Полный сценарий короткого видео (30-60 сек) |
| 6 | Мультипликатор | `multiply/` | Одно длинное видео → 5-7 коротких; большая тема → серия |
| 7 | Дистрибьютор | `posts/` | Подписи под площадки (Instagram, Telegram, YouTube) с CTA |
| 8 | Антидетектор | `antidetector/` | ОБЯЗАТЕЛЬНО последним - убрать следы ИИ |
| 9 | Магнит | `lead-magnet/` | Лид-магниты под тему (если ведёшь воронку с опт-ином) |
| 10 | Кузнец | `skill-forge/` | Собрать новый скилл из повторяющегося паттерна работы |

Отдельно - **Сторителлинг-корректор** (`../материал/SKILL-source/storytelling-corrector-SKILL.md`): докручивает черновик по 12 приёмам (хук, К-А-Р-В, ставки, слом ожидания) в формате «Было -> Предлагаю -> Почему». Полезен для карточек товара и кейсов клиентов.

Как вызвать один скилл в Claude Code:
```
Примени разведчика в режиме История к этому тексту: [текст]
(прочитай ../материал/SKILL-source/extracted/content-system/skills/scout/SKILL.md)
```

## Часть 5. Антидетектор - обязательный финальный проход

Любой текст перед публикацией проходит через антидетектор. Используй **полную версию**: `../материал/SKILL-source/antidetector-full-SKILL.md` (52 паттерна, quad-pass аудит).

Жёсткие правила:
- **Ничего не выдумывать.** Только форма меняется, факты/цифры/цитаты - только из исходника.
- **HARD BANS** - «не просто X, а Y», «в современном мире...», «является» чаще 1 раза на 500 слов - удалять всегда.
- **Quad-pass** перед сдачей: (1) детектор паттернов, (2) чтение глазами случайного читателя, (3) проверка ритма («кардиограмма»), (4) начало пунктов списков - не должны повторяться.
