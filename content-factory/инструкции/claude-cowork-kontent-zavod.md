# Контент-завод на Claude Cowork - инструкция по сборке

Синтез инструкции из курса Георгия Ривера (гайды, скиллы, транскрипт видео) - источники лежат в [`../материал/SKILL-source/`](../материал/SKILL-source/). Не копипаста оригиналов, а переработка под задачи этого проекта.

## Это другой слой, чем GeeLark-завод

В `content-factory/INDEX.md` уже описан конвейер: **видео с фабрик -> обработка -> публикация через GeeLark-профили -> Linktree -> Shopify**. Эта инструкция - про звено **«обработка»**: как одним промтом превращать одну единицу сырья (сценарий, транскрипт, история) в несколько готовых текстовых форматов (посты, сценарий рилса, статья, тред), и как заставить Claude Cowork делать это автоматически по расписанию.

GeeLark остаётся слоем **дистрибуции** (публикация под множеством прогретых аккаунтов). Этот "завод" - слой **производства текста**. Они не конкурируют, а соединяются: то, что здесь сгенерировано, дальше редактируется человеком и уходит в GeeLark-профили на публикацию.

**Важно при настройке брендбука (шаг 2.2):** голос должен быть голосом MebelShop/владельца бизнеса (см. `../../ai-clone/voice/`, `../../business/audience/avatar.md`), а не личный блог автора курса - система нейтральна к нише, но без правильного брендбука выдаёт «умного человека вообще», не голос магазина.

## Два режима работы

- **Ручной (Claude Chat/Project).** Собираешь систему один раз, вызываешь скиллы командами вручную, когда нужно что-то одно.
- **Автоматический (Claude Cowork).** Тот же набор скиллов, но раз в день по расписанию сам мультиплицирует новый сценарий в набор контента - без твоего участия, кроме как положить сырьё в папку.

Ниже - сборка сразу под автоматический режим (ручной - подмножество этих же шагов без раздела «Cowork-автоматизация»).

## Часть 1. Установка один раз

### 1.1 Собери контент-систему как проект в Claude

10 скиллов, передающих работу по цепочке `Идея -> Фокус -> Производство -> Чистка -> Монетизация`. Установка - плагином:

Claude -> **Cowork** (не обычный чат) -> **Customize** (чемоданчик слева) -> **Plugins** -> **+** -> «Загрузить свой плагин» -> перетащить файл [`../материал/SKILL-source/content-system-georgii-rivera.zip`](../материал/SKILL-source/content-system-georgii-rivera.zip).

Все 10 скиллов появятся сразу. Если плагины не поддерживаются в твоей версии - копируй `SKILL.md` каждого скилла вручную (лежат в `../материал/SKILL-source/extracted/content-system/skills/*/SKILL.md`).

### 1.2 Заполни брендбук

Шаблон - [`../материал/SKILL-source/extracted/content-system/brandbook-template.md`](../материал/SKILL-source/extracted/content-system/brandbook-template.md). Заполняй под MebelShop, не под личный бренд: аудитория - покупатели мебели из Китая (РФ/РБ/США/Европа), голос - из `ai-clone/voice/tone.md` и `vocabulary.md`, стоп-слова - из `ai-clone/voice/stop-words.md`. Половина скиллов читает этот файл, чтобы писать нужным голосом - без него результат нейтральный.

Положи заполненный брендбук в тот же проект Claude, где стоят скиллы.

### 1.3 Создай локальную копию проекта на компьютере

Критично для автоматизации и для защиты от блокировки аккаунта Claude: Cowork работает с файлами физически на диске, а не только в облаке. Если аккаунт забанят - все наработки уже у тебя на компьютере.

Создай папку (например `content-zavod-mebelshop/`), скопируй туда все файлы, которые положил в проект на шаге 1.1-1.2 (скиллы, брендбук). Отдельно создай в ней пустую папку **«Новый сценарий»** - точка ежедневного ручного ввода сырья.

### 1.4 Подключи Cowork к этой папке

В Cowork: левое меню -> **Проекты** -> **Создать** -> «Подсоединиться к нашей текущей папке» -> выбрать папку из 1.3 -> **Создать**.

### 1.5 Мастер-промт цепочки

Пробел: оригинальный «ПРОМТ ДЛЯ КОНТЕНТ-ЗАВОДА» из курса лежит в Yandex Docs и не смог быть прочитан (см. «Пробелы» внизу). До экспорта - собери мастер-промт по логике транскрипта и таблицы скиллов ниже:

```
Прочитай файл(ы) из папки «Новый сценарий» - это сырьё (сценарий/транскрипт/история)
для сегодняшнего контента. Прогони через цепочку:

1. /director - свериться с целью (если цель не задана в брендбуке - использовать
   «продажи MebelShop через соцсети»)
2. /scout, режим «История» - вытащить углы из сырья
3. /hook - открытие от кульминации для самого сильного угла
4. /reels - сценарий короткого видео (Reels/Shorts/TikTok) для этого угла
5. /multiply, режим «Нарезка» - если сырьё длинное, разбить на 5-7 самостоятельных роликов
6. /posts - подписи под площадки (Instagram, Telegram, YouTube) с CTA
7. /antidetector - обязательный финальный проход по каждому тексту

Сохрани результат в подпапки «Новый сценарий/готово/[дата]/»: посты, сценарий,
статья, треды - отдельными файлами. Не публикуй нигде - только сохрани локально.
Отчитайся, что создано и где лежит.
```

Вставь свою версию (или восстановленный оригинал) в раздел **«Инструкции»** проекта Cowork.

### 1.6 Настрой повторяющуюся задачу

В Cowork справа -> **+** -> новая задача:
- **Промт** - текст из 1.5 (или ссылка на файл-инструкцию)
- **Название** - латиницей (например `kontent-zavod-mebelshop`)
- **Повтор** - ежедневно, время по своему графику (например 12:00)
- Сохранить -> задача станет зелёной (активна)

**Обязательное условие:** ноутбук должен быть включён (не спать, крышка не закрыта) в момент запуска - иначе задача не сработает.

## Часть 2. Ежедневный цикл

1. **До времени запуска** - положить в «Новый сценарий» новое сырьё: транскрипт видео с фабрики, история клиента, факт о товаре, что угодно текстом.
2. Cowork запускается по расписанию, читает сырьё, прогоняет через цепочку скиллов, сохраняет результат в подпапку.
3. **Просмотреть и отредактировать** результат - это не опция, а обязательный шаг.
4. **Публикация - всегда вручную** (или через делегата/помощника), никогда не автоматизировать. Все платформы (TikTok, Instagram, YouTube и т.д.) активно детектят синтетический бот-контент - автопостинг убивает аккаунт быстрее, чем помогает.
5. Удалить обработанный файл из «Новый сценарий», положить сырьё для следующего дня.

Ключевая мысль курса: ИИ - подрядчик, ты - тот, кто решает, что идёт в производство (даёшь сырьё) и что уходит в публикацию (проверяешь готовое). Полностью замкнутый цикл без человека даёт бесконтрольный контент, поэтому оба края - вход и выход - остаются ручными по дизайну, не по недоделке.

## Часть 3. Цепочка скиллов (справочник)

| # | Скилл | Команда | Когда вызывать |
|---|---|---|---|
| 1 | Директор | `/director` | Проверить: работает ли контент на цель (продажи MebelShop) |
| 2 | Разведчик | `/scout` | Достать углы из сырья - режимы «Сигнал» / «История» / «Вопросы» |
| 3 | Архитектор | `/youtube-pro` | Идеи/структура/упаковка для длинных видео (если формат подходит) |
| 4 | Хук-мастер | `/hook` | Открытие от кульминации для любого формата |
| 5 | Сценарист | `/reels` | Полный сценарий короткого видео (30-60 сек, до 5 битов) |
| 6 | Мультипликатор | `/multiply` | Одно длинное видео -> 5-7 коротких; большая тема -> серия; выстрелило -> продолжение |
| 7 | Дистрибьютор | `/posts` | Подпись + CTA под конкретную площадку, или рассылка |
| 8 | Антидетектор | `/antidetector` | ОБЯЗАТЕЛЬНО последним - убрать следы ИИ (см. часть 4) |
| 9 | Магнит | `/lead-magnet` | Лид-магниты под тему (если ведёшь воронку с опт-ином) |
| 10 | Кузнец | `/skill-forge` | Собрать новый скилл из повторяющегося паттерна работы |

Полные файлы каждого скилла - `../материал/SKILL-source/extracted/content-system/skills/*/SKILL.md`.

Отдельный скилл вне основной десятки - **Сторителлинг-корректор** (`/story`): не генерирует, а докручивает уже готовый черновик по 12 приёмам (хук, К-А-Р-В, ставки, слом ожидания) в формате «Было -> Предлагаю -> Почему». Полезен для карточек товара и кейсов клиентов. Файл: `../материал/SKILL-source/storytelling-corrector-SKILL.md`.

## Часть 4. Антидетектор - обязательный финальный проход

Любой текст перед публикацией проходит через `/antidetector`. Три версии в материалах (короткая в плагине, полная `antidetector-full-SKILL.md`, базовая `Убирает признаки ИИ текста.txt`) - используй **полную**, она включает 52 паттерна и quad-pass аудит.

Жёсткие правила (нарушать нельзя даже ради скорости):
- **Ничего не выдумывать.** Только форма меняется, факты/цифры/цитаты - только из исходника.
- **HARD BANS** - конструкции вроде «не просто X, а Y», «в современном мире…», «является» чаще 1 раза на 500 слов - удалять всегда, не обсуждая.
- **Quad-pass** перед сдачей: (1) детектор паттернов, (2) чтение глазами случайного читателя, (3) проверка ритма предложений («кардиограмма»), (4) проверка, что пункты списков не начинаются одинаково.

Полная таблица HARD BANS и каталог 52 паттернов - в файле `antidetector-full-SKILL.md`.

## Часть 5. Расширения (опционально)

### Карусели для Instagram

Три готовых промта в `../материал/SKILL-source/extracted-text/Промты для генерации каруселей для Инстаграм.txt`:
1. Только текст -> карусель на 7 слайдов (хук/контекст/2 инсайта/напряжение/развязка/CTA)
2. Текст + брендбук -> тот же формат, с фильтром антидетектора и планом на утверждение перед генерацией
3. Текст + брендбук + референс-изображения (NanoBanana) -> подбор изображения под настроение каждого слайда

Для генерации самих PNG нужны коннекторы Figma/Canva (Cowork -> `+` -> Connectors). Гайд по составлению JSON-промта для изображений - `../материал/SKILL-source/extracted-text/JSON-промты для генерации изображений.txt`.

### Презентации и майндкарты

Через коннекторы: Gamma - презентации, MIRO - майндкарты. Подключаются один раз, дальше Cowork подхватывает их автоматически при упоминании в промте.

## Часть 6. Безопасность аккаунта Claude

Это отдельно от защиты Shopify/AdsPower (см. `../../shopify-tools/PLAYBOOK.md`) и от рисков GeeLark-аккаунтов (см. `../accounts.md`, `../payments-risks.md`) - здесь речь про сам аккаунт Claude, которым управляется завод.

- **Работать в Cowork/Projects, не в обычном Chat.** В обычном чате вся работа живёт только в облаке - бан аккаунта = потеря всего. Cowork синхронизирует файлы на диск.
- **Экспорт данных раз в месяц.** Settings -> Privacy -> Export Data -> выгрузка за всё время. Доступно даже заблокированным аккаунтам.
- **Выгрузка скиллов и памяти** - раз в месяц отдельными промтами прямо в чате:
  - «Найди все мои скиллы. Собери их в один архив и пришли мне его в этот чат.»
  - «Выведи всё, что ты обо мне помнишь, полностью и пришли дополнительно файлом.»
- **При бане:** сначала Export Data (спасает наработки), потом апелляция через форму Anthropic (шаблон письма и ссылки - в `../материал/SKILL-source/extracted-text/Гайд_Безопасное_использование_нейросетей_Георгий_Ривера.txt`, ответ занимает 1-2 недели, шанс восстановления невысокий).
- **Регистрация/оплата из РФ/СНГ:** прогрев аккаунта 2-3 дня на бесплатном тарифе перед платным, страна номера/карты/VPN должна совпадать, не использовать съёмные/шаренные номера (бан одного тянет за собой все аккаунты на этот номер), не переключать VPN между странами на разных устройствах одновременно.

## Пробелы - что нужно доснять

Три файла из курса лежали в Yandex Docs (`.webarchive`-снимки браузера) - Яндекс.Диск подгружает содержимое документа через JS/API уже после загрузки страницы, поэтому в статичном снимке страницы текста нет, только пустая оболочка редактора. Извлечь не удалось.

1. **«ПРОМТ ДЛЯ КОНТЕНТ-ЗАВОДА»** - судя по транскрипту, это и есть точный мастер-промт для автоматической Cowork-задачи (шаг 1.5 выше собран по описанию из транскрипта, не это оригинал).
2. **«РОЛИ КОМАНДЫ ВНУТРИ ТЕБЯ»** - похоже на исходную инструкцию проекта из раздела «Чат», возможно мульти-персона фреймворк (команда ролей внутри одной модели). Не восстановлено.
3. **«Убирает признаки ИИ текста»** (webarchive-версия) - не критично, содержание уже есть в `antidetector-full-SKILL.md` и `Убирает признаки ИИ текста.txt` (эти читались из docx, а не webarchive).

**Что сделать:** открой каждый документ в Яндекс.Документах -> Файл -> Скачать как -> `.docx` (или PDF) -> сохрани в ту же папку `SKILL` на Google Диске. При следующей сессии скажи «подтяни новые файлы из SKILL» - синхронизирую через rclone и доработаю пункты 1.5 и «Роли команды» этой инструкции.

Также не полностью прочитан гайд «33 способа использовать Claude Cowork» (`Gaid_Claude_Cowork_Georgii_Rivera.pdf`) - его текстовый слой в PDF повреждён (шрифт без корректной Unicode-карты, OCR на сервере недоступен: нет `tesseract`, нет прав `sudo` на установку). Прочитаны только первые 2 страницы (что такое Cowork). Остальные 32 пункта - общие идеи автоматизации (клонирование голоса, CRM, финансовые дашборды, персональный ассистент), не специфичны для контент-завода - можно дочитать по требованию через рендер страниц в изображения.
