# Методология mastery

## Принцип

Один автор = один файл. Только методы — не пересказ.

У каждого великого есть 1-2-3 идеи, которые изменили способ думать или действовать. Именно их сюда. Всё остальное — шум.

## Формат файла

```markdown
# Имя Автора

**Кто:** одно предложение.
**Область:** маркетинг / продажи / мышление / ...

## Метод 1: [название]
Суть в 2-3 предложениях.
Как применяю: конкретно.

## Метод 2: [название]
...
```

## Правила

1. Не больше 3 методов на автора — если кажется что важно всё, значит не понял ничего
2. Пиши как применяешь лично, не как написано в книге
3. Добавляй только то, что проверил или проверяешь прямо сейчас
4. Устарело — удали или обнови. Эта папка живая, не архив
