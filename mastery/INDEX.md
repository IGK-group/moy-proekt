# Mastery — личный совет директоров

## Что это

Концентрат методов лучших умов мира по областям, которые важны мне прямо сейчас.

**Mastery — не библиотека и не конспекты.** Это рабочие инструменты: 1-2-3 метода от каждого автора, которые я реально применяю. Не пересказ книги — только суть, только то, что работает.

## Чем отличается от skills

| Mastery | Skills |
|---|---|
| Чужие методы, адаптированные под меня | Мои собственные навыки |
| Как думают великие | Как действую я |
| Читаю когда нужна чужая рамка | Читаю когда нужно вспомнить свои правила |

## Правило наполнения

- **1 автор = 1 файл.** Не пересказывай книгу — выдели 1-2-3 метода которые меняют поведение.
- **Только методы, не биографии.** Кто такой автор — одно предложение. Остальное — как применять.
- **Проверено на себе.** Если метод не попробовал — не добавляй. Или добавь с пометкой «в работе».

## Структура

```
mastery/
├── INDEX.md              ← этот файл
├── README.md             ← методология папки
└── [область]/            ← одна папка = одна область
    └── [автор].md        ← один файл = один автор
```
