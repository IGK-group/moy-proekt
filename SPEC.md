## 1. Сквозные правила (действуют везде)

- **Текст / описание НИКОГДА не наложены на изображение.** Картинка — в своём боксе,
  текст — в отдельной панели рядом/ниже на сплошном фоне. Проверял многократно, это жёсткое.
- **Перебрендирование:** с любого товара убрать чужие логотипы и надписи (DREAME, UWANT,
  CHOVER, KeLeDi, K-003 и т.п.). Фирменный акцент — мятно-бирюзовый: `#12b1a6` (акцент темы),
  `#34D3C0` (свечение индикаторов на рендерах).
- **Масштаб товара консистентный** внутри одного ряда/ротации. Не «гигант», ориентир —
  реальные пропорции с исходных фото 1688.
- **Обратимость:** правки только в неопубликованной теме `GlideHome REDESIGN`. Публикация —
  ТОЛЬКО по явному «публикуй» от Гены. Откат: Publish `Horizon BACKUP 2026-09-01`.
- **Гена смотрит с iPhone.** Тестировать в НАСТОЯЩЕМ Safari, не во встроенном браузере Telegram
  (он перехватывает горизонтальные свайпы — даёт ложное «не работает»).
- **claude.ai артефакты Гене недоступны** (Китай) — результат всегда дублировать в чат.
- **Самопроверка перед показом:** открыть свои картинки, проверить пропорции, отсутствие
  наложения текста, отсутствие обрезки товара.

## 2. HERO — десктоп

- 5 слайдов, порядок: **Vac Station → Vac Slim → Window Pro → Stick V400 → Mite Pro**.
- Убраны из ротации: W17S, DYP, Window Lite (файлы в `slides/`, вернуть вставкой разметки).
- Слайд 1 — тёмная студия (Vac Station). Слайды 2-5 — светлые дизайнерские интерьеры.
- Картинки десктопа: `slides/*.jpg` ~1920×823 (21:9), `background-size:cover`, товар в левой
  трети, текст справа (`text-right`), градиентный scrim под текстом для читаемости.
- Индикатор: полосы `.hero-dots button` ширина **140px**, **без** прогресс-заливки
  (анимацию `dotfill` и `::after` убрали — Гена просил одинаковые полоски).
- Автопрокрутка 6с (`SLIDE_MS`), пауза на hover, стрелки + точки.
- Кнопок в слайде до двух: основная `.btn-primary` + вторичная `.btn-on-dark`.

## 3. HERO — мобильный (`<=768px`) — самое проработанное

- **У каждого слайда своя ВЕРТИКАЛЬНАЯ картинка** `slides/*-m.jpg` (3:4, ~1195×1600).
  Товар — герой, ~70–82% высоты кадра, ЦЕЛИКОМ, по центру.
- `.slide-bg` берёт `--img` (десктоп) или `--img-m` (мобильный) + `--pos-m` из inline-стиля.
  Бокс `aspect-ratio: 3/4` (= пропорции картинки), `width:100%`, БЕЗ `height`/`max-height`.
- **Мобильная карусель:** `.slides { display:flex }`, каждый `.slide { flex:0 0 100% }`,
  сдвиг `transform: translateX(-idx * ширину_слайда_в_px)`. Класс `.no-anim` убирает
  `transition` на время драга. Доводчик `transition: transform .34s ease`.
- **Свайп:** Pointer Events (основное) + Touch Events (фолбэк), общий guard `pLock`.
  Порог ~38–40px, горизонталь должна быть >= вертикали. На краях — сопротивление ×0.35
  (резинка, без перехода на противоположный край). Перескок через край (wrap) — с `.no-anim`
  (мгновенно, без пролёта всей ленты).
- **Страница НЕ должна двигаться при свайпе:** `touch-action: pan-y` на `.hero`,
  `e.preventDefault()` в `touchmove` когда драг распознан горизонтальным (listener НЕ passive),
  `body { overflow-x: clip }`, `.hero { overflow: hidden }`.
- Под картинкой — **компактная тёмно-бирюзовая (`--ink` = #0f2831) панель:**
  eyebrow + заголовок + ОДНА основная кнопка. Вторичная кнопка `.btn-on-dark` и длинный
  подзаголовок `<p>` — `display:none` на мобильном.
- **Точки — наложены на низ картинки** (`position:absolute`, низ картинки, не низ слайда).
  `filter: drop-shadow(...)` для читаемости на светлых фото. Неактивные — `rgba(255,255,255,.55)`,
  активная — сплошной белый. **Тёмный градиент-скрим под точками НЕ делать** — Гена читает
  его как «тёмные полосы», не нравится.
- Стрелки `.hero-arrow` — `display:none` на мобильном.
- Высота панели у слайдов разная (разные заголовки) → `.slides { align-items:flex-start }`,
  `.hero { background: var(--ink) }` чтобы разница высот не давала шва.

## 4. Слайды hero — требования к картинкам (генерация Higgsfield `gpt_image_2`)

- Светлые тона, красивый дизайнерский интерьер, большие/панорамные окна.
- Товар **реалистичен**: стоит на полу / присосан к стеклу, НЕ висит в воздухе; контактная
  тень. Вертикальный пылесос — **у стены**, не посреди комнаты.
- Товар развёрнут **лицом к камере** (виден перёд: бампер, сенсор, дисплей, хват).
- Товар выглядит **ВКЛЮЧЁННЫМ**: свечение кольца/кнопки/индикаторов (мятное #34D3C0).
- **НЕ использовать** «эффект грязных окон» (стекло всегда чистое, прозрачное).
- **Без** световых линий/лучей на полу перед роботом-пылесосом (Гена убрал на слайде 2).
- Референсы товаров: `../taobao-tools/factory_photos/` — `dreame-x50-ultra/`, `6-я/`,
  `фабрики2/18-я/`, `uwant-shop/vac-v400pro-81007/`, `uwant-shop/vac-dabai-cm2306ultra-00631/`.

## 5. Секция категорий («SHOP»)

- **Заголовок секции убран** («SHOP» + слоган «Two lines, one idea…»). Плитки идут
  СРАЗУ под hero (`.cats-section { padding-top: 16px }` на мобильном).
- 3 плитки: **Window Robots / Robot Vacuums / Anti-Mite & Handheld**.
- Фото плиток: `cats/window.jpg` `cats/vacuum.jpg` `cats/handheld.jpg` — **чистые студийные
  рендеры** (нейтральный светло-серый фон, мягкая тень, БЕЗ текста, товар целиком/по центру/
  лицом). Генерация Higgsfield, единый стиль, **отличается от лайфстайл-слайдов hero**.
  - НЕ брать кропы со слайдов (Гена: «те же фото — некрасиво»).
  - НЕ брать фото товаров из витрины Shopify — у всех запечён маркетинг-текст, кропаются грязно.
  - НЕ брать сырые фото фабрик — китайские надписи, коробки, аксессуары.
- Структура плитки `.cat`: `.cat-art` (фото 4:3, `background-size:cover`) СВЕРХУ +
  `.cat-body` (текст на сплошном фоне) СНИЗУ. Текст физически в другом блоке — не оверлей.
- Референсы товаров под рендеры: DYP (окна), jieshi vacuum (робот-пылесос), CM2306 (клещи).

## 6. Где искать ошибки (грабли из прошлых правок)

| # | Симптом | Причина | Правильно |
|---|---|---|---|
| 1 | Тёмная полоса справа от картинки на iOS | `aspect-ratio` + `max-height` вместе → Safari ужимает ширину | Фикс. высота ИЛИ только `aspect-ratio`, без `max-height`; `width:100%` |
| 2 | Товар обрезан сверху/снизу | `cover` в боксе с иным соотношением сторон, чем у картинки | Бокс = пропорции картинки (`aspect-ratio:3/4`) |
| 3 | «Тёмные зоны/полосы» на слайдах | Градиент-скрим `::after` под текст/точки | На мобильном скрим не нужен (панель отдельно); точкам — `drop-shadow` |
| 4 | При свайпе едет вся страница | passive `touchmove` без `preventDefault`, нет `touch-action` | `touch-action:pan-y`, `preventDefault` при гориз. драге, listener не passive |
| 5 | Свайп «не работает» | Тест во встроенном браузере Telegram (перехватывает жест) | Тестировать в Safari; в коде — Pointer Events + touch фолбэк |
| 6 | Резкий переход слайдов | `display:none/block` вместо анимации | Трек `transform:translateX` + `transition .34s`, `.no-anim` на драг |
| 7 | Пролёт всей ленты при переходе последний→первый | Анимированный `translateX` на большой скачок | wrap-переход с `.no-anim` (мгновенно) |
| 8 | Плитки категорий выглядят дёшево/повторно | Переиспользованы картинки слайдов | Отдельные студийные рендеры под плитки |
| 9 | Не получается чистая плитка из фото витрины | В фото Shopify запечён маркетинг-текст + лого | Генерировать чистый рендер, референс — товар из витрины |
| 10 | Секция после hero «обрезана»/голая | Резкий стык картинка → белая секция | Завершать hero тёмной панелью; секцию категорий подтянуть вверх |
| 11 | AI-рендер: товар висит / посреди комнаты / луч на полу / гигант | Слабый промпт | Явно: контактная тень, у стены, без лучей, масштаб как на 1688, лицом к камере, включён |
| 12 | Кнопка «Shop» под сгибом на мобильном | Слишком высокая картинка hero | Панель компактная; прикропе картинки — товар с запасом полей |

## 8. Перенос в Shopify — как (решено 2026-09-02)

- **Исполнение:** Claude через Admin API (Asset API) пишет секции/шаблоны/CSS в
  неопубликованную тему `GlideHome REDESIGN`. Меню и часть настроек — Гена в Theme Editor.
- **Точность:** секции 1-в-1, кастомные (свой Liquid + CSS + JS, включая мобильную
  тач-карусель с драгом).
- Тема-база — **Horizon** (блочная): `templates/*.json` ссылаются на `sections/*.liquid`,
  секции содержат `blocks/*.liquid`. Кастомные секции добавляем как `sections/glide-*.liquid`
  со `{% schema %}` и подключаем в `templates/index.json`.
- Порядок работ: сначала главная (`index`) целиком и вылизать, потом `line` / `product` /
  `support` / `about`.
- Правило репо №3: одноразовый/неиспользуемый код удалять в том же коммите.
